# Nemotron VoiceChat Codec

The 22.05 kHz audio codec embedded in NemotronLabs VoiceChat: a
channels-last ConvNeXt encoder/decoder over 16-point STFT
real/imaginary features (hop 4), a probabilistic residual vector
quantizer whose 31 books are plain Gaussian means, and a
magnitude/phase decoder head with an envelope-clamped iSTFT.

## Model Overview

```text
Mono PCM (B, S)
   |
   v
_spectrogram: zero pad (n_fft - hop) / 2 = 6 both sides, periodic
Hann(16), frame at hop 4, rFFT -> [real(9); imag(9)] = (B, 18, T)
   |
   v
Encoder: 1x1 conv (18 -> 384, no bias)
   per stage (channels 384 -> 768 -> 1536, strides 7 -> 7 -> 9):
     blocks_per_stage=3 x ConvNeXtBlock1d + Conv1d(k = s, stride = s)
   final projection to latent_dim 512                   (B, T, 512)
   |
   v
PRVQ encode: per quantizer q of 31, Euclidean argmin over 1024
Gaussian means, subtract the winner (residual); codes (B, 31, T)
   |
   v
PRVQ decode: sum of means                                (B, T, 512)
   |
   v
Decoder: per stage (reversed) ConvTranspose1d(k = s, stride = s)
   + 3 x ConvNeXtBlock1d; final 1x1 conv (384 -> 18)     (B, T, 18)
   |
   v
Split magnitude logits (first 9 rows) and phase (last 9):
   magnitude = 100 * exp(-softplus(-logit + ln 100))
   imag bins of DC and Nyquist forced to 0
iSTFT (hop 4): per-frame irfft, clamp to the window envelope,
   window, overlap-add, divide by max(sum w^2, 1e-10)
crop (n_fft - hop) / 2 samples per side               (B, 1, S')
```

ConvNeXtBlock1d: causal depthwise conv (left pad `k - 1`, k = 7),
channel LayerNorm (eps 1e-6), pwconv1 to 4x channels, exact GELU,
pwconv2 back, residual.

## Verification

- **Fixture parity (tiny seeded codec, 2 input lengths + random-codes
  decode)**: codes exact per quantizer with quantization margins
  recorded in `traces.json` (min margin 0.039 / 0.098 across tags),
  latents within 1e-5 relative, decoded waveforms within 1e-5
  relative. Fixtures: `testdata/nemotron_voicechat/`, regenerated by
  `tools/gen_nemotron_voicechat_fixtures.py` from the pinned commit
  (see the generator header for the exact command).
- **Real checkpoint**: opt-in gate via
  `TURBOSPARK_NEMOTRON_VOICECHAT_MODEL=<dir>` (config.json +
  model.safetensors). Skipped when unset; not run on this machine.
- Full-duplex STS task quality is out of scope for this crate.

## Scope and Divergences

- Batch `encode` / `decode` only. The streaming `decode_step` path
  (per-layer `CausalConv1dCache`, the iSTFT spectrogram-overlap cache,
  and the flush bookkeeping) is not ported; batch mode left-pads each
  causal conv, which is the cache's reset state.
- `prvq.variance_list` tensors are loaded strictly (a checkpoint
  missing them is refused) to mirror the reference hierarchy, but they
  are unused by the batch contract.
- Decode length is exact per token count (`tokens * 1764` on the
  default config); encode drops any input tail shorter than one token.

## Parameters (default config)

| Parameter | Value |
|---|---|
| Sample rate | 22 050 Hz |
| STFT | n_fft 16, hop 4, periodic Hann, 9 bins |
| Channels | 384 x (1, 2, 4), 3 ConvNeXt blocks per stage |
| Downsampling | 7 x 7 x 9 (x441), token = 1764 samples, 12.5 Hz |
| Latent dim | 512 |
| Quantizers | 31 x 1024 Gaussian means |
