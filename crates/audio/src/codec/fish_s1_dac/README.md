# Fish S1 DAC

The fishaudio fish-speech S1 acoustic tokenizer: a causal DAC (44.1
kHz, hop 512) whose last encoder block carries a window-limited
transformer, a downsampled dual residual quantizer (one semantic book
at 4096 codes plus nine acoustic books at 1024, both 8-dim, 2x2
downsample with window-limited pre/post transformers at dim 1024), and
a mirrored transposed-conv decoder with tanh output. One token covers
2048 samples (`frame_length`).

## Model Overview

```text
Mono (B, 1, T), right-pad to frame_length multiples
   |
   v
Encoder: causal WN conv (1 -> 64, k7) -> 4 blocks (strides 2,4,8,8,
  channels doubling 64 -> 1024): 3 causal ResidualUnits (dil 1,3,9)
  + Snake + strided causal WN conv (+ window-512 transformer with
  4 layers on the last block) -> Snake -> WN conv (k3) to latent 1024
   |
   v
Quantizer (downsample 2x2 to frame rate):
  [causal conv k=s s=s -> ConvNeXt block] x2
  -> pre window-128 transformer (8 layers, 16 heads, dim 1024)
  -> semantic RVQ (1 book x 4096, dim 8)
  -> greedy residual RVQ (9 books x 1024, dim 8) on the semantic residual
  -> post window-128 transformer
  -> [causal transposed conv + ConvNeXt] x2 back to hop rate
   |
   v
Decoder: causal WN conv (1024 -> 1536, k7) -> 4 DecoderBlocks
  (strides 8,8,4,2; Snake + transposed causal WN conv + 3 residual
  units) -> Snake -> causal WN conv (k7) -> tanh
```

ConvNeXt blocks: causal depthwise conv (plain torch-layout weight,
k7), LayerNorm (eps 1e-6), pwconv1 (bias), exact GELU, pwconv2
(bias), learned per-channel gamma, residual. Transformers: pre-norm
RMSNorm, fused QKV with interleaved RoPE (base 10000, head dim 64),
additive window-limited causal masks (0 / -1e9), learned LayerScale
gammas, SwiGLU FFN, post-norm RMSNorm.

All convolutions use the causal padding contract: left pad
`kernel_eff - stride` plus a right pad to a stride multiple;
transposed convs trim `kernel - stride` from the right. Weight norm
folds at load from the torch-layout `weight_g (dim0, 1, 1)` /
`weight_v` pairs.

## Verification

- **Fixture parity (tiny mirrored geometry of `build_ae()`)**: codes
  exact per book (semantic + acoustic) for two input lengths, decoded
  waveforms (relative, 1e-3 gate -- the tiny random-weight stack
  amplifies like the sibling fixtures), and a random-codes decode.
  Fixtures: `testdata/fish_s1_dac/`, regenerated by
  `tools/gen_fish_s1_dac_fixtures.py` from the pinned commit. The
  transformers' `freqs_cis` tables and causal masks are derived state
  and are recomputed, never loaded.
- **Real checkpoint**: opt-in gate via `TURBOSPARK_FISH_S1_DAC_MODEL`
  (model.safetensors; config.json optional, geometry defaults to
  `build_ae()`). Skipped when unset; not run on this machine.

## Scope and Divergences

- The causal (`build_ae()`) geometry only; the non-causal variant
  (DAC(causal=False)) is not ported.
- `encode_zq` / `decode_zq` / `from_latents` (continuous-latent entry
  points) are not ported; the codes contract covers `encode` /
  `decode`.
- The decoder-side `decoder_transformer_layers` argument exists
  upstream but is unused there (the Decoder never builds
  transformers); the port does not carry it.
