# Higgs Audio Acoustic Tokenizer

The HiggsAudioV2 acoustic tokenizer: a DAC-shaped acoustic encoder and
decoder with Snake activations (plain convolutions, `norm="none"` --
unlike SNAC/Descript/DACVAE there is no weight norm), an 8-book
residual vector quantizer with per-book `project_in` / codebook /
`project_out`, and the `fc2` bridge from the 1024-dim quantizer space
to the 256-dim decoder input. The decode path turns 25 Hz token
frames into 24 kHz audio at a 960-sample hop.

## Model Overview

```text
Decode (tokens -> waveform), the batch contract:
  codes (T, 8) int32
  |
  v
RVQ decode: sum over 8 books of project_out(codebook[code])   (T, 1024)
  |
  v
fc2: Linear(1024 -> 256)                                      (T, 256)
  |
  v
AcousticDecoder (channels-last): WN-free Conv1d(256 -> 1024, k7, pad 3)
  per block (strides 8,5,4,2,3; channels halving 1024 -> 32):
    Snake1d -> ConvTranspose1d(k = 2s, stride s, pad s/2, plain),
    trimmed to T_in * s -> 3 x ResidualUnit (dilations 1, 3, 9)
  Snake1d(32) -> Conv1d(32 -> 1, k7, pad 3)               (T*960, 1)

Encode (acoustic half; the semantic fusion needs wav2vec2):
  Mono (T, 1) -> Conv1d(1 -> 64, k7, pad 3)
  per block (channels 64 -> 2048, strides 8,5,4,2,3,
             conv pad forced to ceil(s / 2)):
    3 x ResidualUnit -> Snake1d -> strided Conv1d(k = 2s)
  Snake1d(2048) -> Conv1d(2048 -> 256, k3, pad 1)             (T', 256)
```

ResidualUnit: Snake, dilated k7 conv (symmetric pad `3 * dilation`),
Snake, k1 conv, symmetric crop-add. All activations are the guarded
Snake `x + sin(a x)^2 / (a + 1e-9)`.

## Verification

- **Fixture parity (tiny seeded tokenizer)**: acoustic features
  (relative, 1e-4 gate -- the tiny random-weight stack amplifies to
  ~6e10 where f32 order noise is ~1e-5), RVQ codes exact with margins,
  RVQ reconstruction, and full token decode (relative, 1e-4). Fixtures:
  `testdata/higgs_audio/`, regenerated by
  `tools/gen_higgs_fixtures.py` from the pinned commit. The reference
  hardcodes channel ladders and the 1024/256 dims as class/constructor
  constants, so the generator mirrors the `__init__` bodies at shrunk
  dims with identical weight keys and records the mapping in
  `tiny_config.json` (`quantizer_latent_dim`, `decoder_input_dim`).
- **Real checkpoint**: opt-in gate via `TURBOSPARK_HIGGS_AUDIO_MODEL`
  (config.json + model.safetensors, decode path only). Skipped when
  unset; not run on this machine.

## Scope and Divergences

- Decode path, acoustic encoder, and RVQ are ported. The full `encode`
  fuses a wav2vec2 (HuBERT) semantic tower through `encoder_semantic`
  and `fc`; that tower is an STT model outside the codec crate and is
  not ported. `encode_acoustic` / `rvq_encode` expose the acoustic
  half; semantic fusion happens in a future STT integration.
- The sinc resampler (`_sinc_resample`, torchaudio-compatible) is part
  of the unported fusion path and is not ported.
- Config fields `quantizer_latent_dim` (default 1024) and
  `decoder_input_dim` (default 256) exist so fixtures can shrink what
  the reference hardcodes; real checkpoints keep the defaults.

## Parameters (default config)

| Parameter | Value |
|---|---|
| Sample rate | 24 000 Hz |
| Acoustic hop | 8 x 5 x 4 x 2 x 3 = 960 (25 tokens/s) |
| Encoder channels | 64 -> 2048, latent 256 |
| Decoder channels | 256 -> 1024 -> ... -> 32 -> 1 |
| Quantizer | 8 books x 1024 codes, dim 64, latent 1024 |
