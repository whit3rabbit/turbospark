# StepAudio2 Token-to-Wav Pipeline

StepAudio2 is not an encode/decode tokenizer: it is the conditional
generative half of Step-Audio-2 that renders discrete speech tokens plus a
speaker prompt into a 24 kHz waveform. One S3-token stream and one speaker
prompt go through a flow-matching DiT (tokens -> mel), and an NSF-iSTFT
vocoder renders mel -> audio.

## Upstream References and URLs

- **Reference implementation**: [`mlx_audio/codec/models/stepaudio2/`](https://github.com/Blaizzy/mlx-audio/tree/e1b19b9054bf163f5d812221a54fcc346f1890e9/mlx_audio/codec/models/stepaudio2) at mlx-audio `e1b19b9054bf163f5d812221a54fcc346f1890e9`, together with the chatterbox `s3gen` modules it imports (`transformer/`, `hifigan.py`, `f0_predictor.py`, `xvector.py`, `mel.py`).
- **Upstream checkpoint**: Step-Audio-2 token2wav (flow.pt / hift.pt / campplus.onnx), 24 kHz output, consumes the 25 Hz S3 FSQ tokenizer (6561 codes; see the [s3 family README](../s3/README.md)).

## Architecture

- **Flow** (`flow.py` `CausalMaskedDiffWithXvec`): token embedding (6561 vocab, `mx.clip`), an espnet relative-position conformer encoder with a pre-lookahead conv, an `Upsample1D` (stride 2, mel-frames-per-token factor), a second conformer stack, and a linear projection to 80 mel dims. The speaker embedding is L2-normalized (+1e-8) and projected; the conditioning is `[prompt_feat, zeros]` over the full (prompt + generated) span.
- **DiT estimator** (`decoder_dit.py`): 16 blocks, hidden 512, adaLN-zero modulation with a 9-way split (msa / mlp / conv shift-scale-gate), qk-norm attention, a causal conv branch (Mish + LayerNorm), and a cos/sin timestep embedder (`t * 1000`). Input assembly is `[x, mu, speaker, cond]` = 320 channels.
- **CFM** (`flow_matching.py`): 10-step Euler over `t_span = 1 - cos(linspace(0,1) * pi/2)` with classifier-free guidance rate 0.7 (cond + uncond batch doubling). `rand_noise` is a checkpoint tensor, so the solve is deterministic.
- **HiFT vocoder** (`hift.py` extending s3gen `HiFTGenerator`): 24 kHz, upsample rates `[8, 5, 3]`, iSTFT n_fft 16 hop 4, NSF sine source with interpolated phase (`use_interpolation=True`), `ConvRNNF0Predictor` (ELU conv stack + linear, absolute value). The output head emits log-magnitude (`exp`) and phase (`sin`) halves that an iSTFT turns into samples, clipped to +/-0.99.
- **CAMPPlus speaker encoder** (`speaker.py`, fused ONNX-export variant): kaldi fbank (Povey window, DC removal, pre-emphasis, HTK mel, log at float epsilon, per-feature mean removal), a 2D-conv ResNet head without internal batchnorms, a strided TDNN conv, three dense CAM blocks (SE-style context gating with a 100-frame zero-padded segment pool) with transit convs, statistics pooling (mean + population std), and an affine-free batchnorm dense head producing the 192-dim embedding.

## Rust Port Notes (details that break parity if missed)

- The espnet `rel_shift` pad/reshape/slice reduces to table index `(T-1) + j - i` for query `i`, key `j`; the positional encoding table (interleaved sin/cos, `exp(-ln(10000)/d * 2i)`) covers positions `[-(T-1), T-1]` reversed, and the reference slices the centered `2T-1` rows.
- The final leaky ReLU before `conv_post` uses the `nn.leaky_relu` DEFAULT slope (0.01), not the `lrelu_slope = 0.1` of the upsample stages.
- The CFM noise window is a strided slice: the checkpoint buffer is `[mel, 50 * 600]` and the reference takes the first `T` frames per channel.
- The DiT speaker broadcast is channel-major (`spks[c]` into every frame of channel `c`), and the final adaLN layer norms BEFORE modulating (`modulate(norm_final(x), shift, scale)`).
- The HiFT sine generator's inference-time randomness (initial phase draw with harmonic 0 zeroed by the reference, plus the sine noise bed) is explicit `SineDraws` input here; `None` means deterministic zeros.
- CAMPPlus details: the fused head has no batchnorms; the residual of a stride-1 CAM resblock shortcut is the block INPUT; the CAM segment pool averages over the zero-PADDED segment length; the SE gate context is per-frame (time-mean broadcasts over frames); `batchnorm_` (affine-free) in the dense head carries NO ReLU.
- MLX `ConvTranspose1d` checkpoints store `[out, K, in]`; the loader transposes to the PyTorch `[in, out, K]` layout the crate kernel expects.

## Scope

Batch-of-one inference with exact lengths (the reference asserts batch 1; all padding masks reduce to all-valid). File loading, resampling, and the S3 speech tokenizer stay outside the port: the caller passes pre-resampled waveforms and prompt tokens, as the runtime does.
