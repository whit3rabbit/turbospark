# BigVGAN (Anti-Aliased Universal Neural Vocoder)

BigVGAN is a neural vocoder in the HiFi-GAN lineage featuring anti-aliased
multi-period activations (AMPBlock) and periodic non-linearities (SnakeBeta).
It converts log mel spectrograms into high-fidelity speech waveforms across
varied acoustic environments.

## Model Overview

```text
Log Mel Spectrogram [num_mels, num_frames]
   |
   v
WnConv1d(num_mels -> upsample_initial_channel, k7)
   |
   v
[UpsampleBlock x |upsample_rates|]
   Each: Transposed WnConv upsampling + Multi-Receptive Field Fusion (MRF)
   MRF: Sum of AMPBlock resblocks (with kernel sizes e.g. [3, 7, 11])
   Each AMPBlock: anti-aliased SnakeBeta activation (2x kaiser sinc upsample ->
   SnakeBeta -> 2x lowpass sinc downsample) + dilated convolutions
   |
   v
Anti-aliased SnakeBeta + WnConv1d(k7) -> tanh -> Waveform
```

### Architecture Specifications

| Property | Value |
|---|---|
| Sample rate | 24 kHz or 22.05 kHz depending on checkpoint |
| Input mel channels | 80 or 100 channels |
| Upsample rates | [8, 8, 2, 2] (cumulative hop 256) |
| Activation | snakebeta (with checkpointed kaiser sinc filters) |
| Normalization | weight_norm on all convolutions |
