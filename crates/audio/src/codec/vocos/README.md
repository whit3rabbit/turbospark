# Vocos (iSTFT-Based Neural Vocoder)

Vocos is an efficient Fourier-based neural vocoder that replaces conventional
multi-stage transposed convolutions with a ConvNeXt feature backbone and an
inverse Short-Time Fourier Transform (iSTFT) synthesis head. It provides
fast audio synthesis with low latency.

## Model Overview

```text
Log Mel Spectrogram [n_mels, num_frames]
   |
   v
ConvNeXt Backbone:
   Input projection: Conv1d(n_mels -> dim, k7)
   [ConvNeXtBlock x num_layers]:
     Depthwise Conv1d(dim, k7) -> LayerNorm -> Linear(dim -> intermediate_dim)
     -> GELU -> Linear(intermediate_dim -> dim) + Residual
   |
   v  latent features [dim, num_frames]
iSTFT Synthesis Head:
   Linear projection -> [n_fft + 2] (log magnitude and unwrapped phase)
   Magnitude: exp(log_mag).clamp(max=100.0)
   Complex spectrum: mag * cos(phase) + i * (mag * sin(phase))
   Hermitian extension -> Complex iFFT -> Overlap-Add with symmetric Hann window
   |
   v
Waveform [samples]
```

### Architecture Specifications

| Property | Value |
|---|---|
| Sample rate | 24 kHz (checkpoint-driven) |
| Front end | Whisper-style centered reflect STFT, HTK mel filterbank |
| Backbone dim | 512 (intermediate 1536, 8 layers) |
| FFT size | 1024 (hop length 256) |
| Synthesis head | Direct magnitude and phase projection + iSTFT |
