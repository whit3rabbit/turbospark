# SNAC (Multi-Scale Neural Audio Codec)

SNAC is a multi-scale neural audio codec in the SoundStream / EnCodec
lineage: a conv encoder with Snake activations, a residual vector
quantizer whose levels run at different frame rates, and a mirrored
transposed-conv decoder. It is the acoustic tokenizer behind several
audio language models (CosyVoice-style LLM speech, Orpheus, CSM-style
TTS stacks) that emit or consume SNAC code levels.

## Model Overview

```text
Mono PCM
   |
   v
Right-pad to multiple of hop * lcm(vq_strides)
   |
   v
Encoder: WN-Conv1d(1 -> encoder_dim, k7) -> [EncoderBlock x |rates|] -> depthwise WN-Conv1d(k7)
         EncoderBlock = 3x ResidualUnit(dilations 1, 3, 9) + Snake + strided WN-Conv1d(k = 2 * stride)
   |
   v  latent frames = samples / hop_length
Residual Vector Quantizer, one level per vq_strides[i]:
   average-pool frames by stride -> in_proj (1x1) -> L2-normalized
   nearest codebook row -> out_proj (1x1) -> repeat_interleave(stride)
   residual = residual - level output
   |
   v  codes: one i32 vector per level
Decoder (codes path): sum of per-level out_proj(codebook rows) -> depthwise WN-Conv1d(k7)
   -> 1x1 -> [DecoderBlock x |rates|] -> Snake -> WN-Conv1d(k7) -> tanh
   DecoderBlock = Snake + transposed WN-Conv(k = 2 * stride) + [NoiseBlock] + 3x ResidualUnit
```

## Verification

Fixtures: `testdata/snac/`, regenerated by `tools/gen_snac_fixtures.py`
(run from the `../mlx-audio` checkout root with the project venv
interpreter; add `--real` to record the deployed checkpoint tensors).
Codes are exact-equality gates; tensors are float-tolerant gates.

- `tiny_a` (depthwise, noise-free, 8/32/64 channels): encoder output
  `z`, quantizer `z_q` + codes, decoder audio, codes-to-audio decode,
  and the encode round trip all match the Python reference. Codes are
  exact; the recorded level-0 VQ distance margins (best vs second
  best > 1e-5) prove no exact-index gate sits on a rounding knife-edge.
- `tiny_b` (dense, noise on, 70-sample input): exercises the
  preprocess right-pad path, the non-depthwise conv paths, and the
  noise terms. The Rust test replays the recorded f32 normal pool
  through `decode_with_noise` and matches the Python decode with the
  same injected draws.
- Isolated level-0 `VectorQuantize` trace: pooled latents, projections,
  and indices match.
- **Real checkpoint gate** (runs when `mlx-community/snac_24khz` is in
  the local HF cache, or set `TURBOSPARK_SNAC_MODEL`): encode of a
  seeded 12 k-sample waveform reproduces all three code levels exactly;
  decode with zeroed noise terms matches the Python zero-noise decode.
- `cargo test -p turbospark-audio --lib codec::snac` (9 tests), plus
  the crate-level portable-target check.

## Reference Deviations (upstream defects at the pinned commit)

1. **LocalMHA refused at load.** The reference's attention block
   expects channels-first input while the surrounding convs pass
   channels-last (`layers.py` / `attention.py` shape mismatch), and its
   `rotate_half` helper inserts a size-1 axis, so `apply_rotary_pos_emb`
   raises for any input. Upstream's own `codec/tests/test_snac.py` uses
   `attn_window_size: None`, and the deployed `mlx-community/snac_24khz`
   config stores `attn_window_size: null`. The Rust loader returns
   `SpeechError::Unsupported` for attention-enabled configs instead of
   decoding with a broken layer.
2. **Transpose conv output_padding = 1.** The reference calls
   `mx.conv_transpose1d(x, weight, stride, padding, dilation, groups)`
   positionally, but MLX's parameter order is `(stride, padding,
   dilation, output_padding, groups)`, so `groups` lands in the
   `output_padding` slot. Every codec transpose conv uses groups=1, so
   the effective output padding is 1 and decode outputs are slightly
   longer than `frames * hop` (e.g. 120907 samples for 120000 input in
   upstream's own test). The port reproduces this exactly.
3. **NoiseBlock draws one normal per channel.** The reference unpacks
   channels-last decoder activations as `B, C, T` and draws
   `mx.random.normal((B, 1, T))` with `T` bound to the channel count,
   so each channel gets one scalar noise applied across all frames.
   The port keeps that behavior and takes the draws from a
   caller-supplied source (`decode_with_noise`), so decode is
   deterministic given a source; `decode` refuses noise-enabled
   checkpoints to avoid silently dropping the terms.

## Usage Notes

- `Snac::encode(&samples) -> Vec<Vec<i32>>` pads internally and returns
  one code vector per level (level 0 is the coarsest).
- `Snac::decode(&codes)` for noise-free checkpoints;
  `Snac::decode_with_noise(&codes, &mut normal_source)` otherwise
  (`|| 0.0` gives the deterministic zero-noise backbone used by the
  fixture gate).
- `Snac::decode_stream`-style context concatenation from the reference
  is not ported; callers concatenate code levels themselves and decode.
- Config parsing follows the reference constructor defaults, so a
  checkpoint `config.json` that omits fields still loads.
