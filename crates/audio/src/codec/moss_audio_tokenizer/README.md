# MOSS Audio Tokenizer

The MOSS-Audio-Tokenizer: a config-driven stack of patching and
windowed-causal transformer modules around a residual lookup-free
quantizer, with channel interleaving for stereo input at 48 kHz.
Convolutions are all kernel-1 with PyTorch
`parametrizations.weight.original0/1` weight-norm tensors folded at
load.

## Model Overview

```text
Mono in -> repeat to `number_channels` (2), pad to a
`downsample_rate` (3840) multiple, channel-interleave to (1, T*C)
   |
   v
Encoder modules (per config; downsample ratios shrink the frame rate):
  PatchedPretransform(patch): (C, T) -> (C*patch, T/patch), lengths / patch
  ProjectedTransformer: input_proj -> pre-norm layers -> output_proj
    attention: fused QKV, finfo-min masks (causal + `delta < context`),
    interleaved RoPE, invalid query rows zeroed before out_proj
    LayerScale vectors are checkpoint parameters
    FFN: bias-free Linear -> exact GELU -> bias-free Linear
   |
   v
Residual LFQ: input_proj (k=1 WN conv) -> per book
  in_proj -> L2-normalize (floor 1e-12) -> nearest normalized codebook
  row (argmax dot) -> emit the RAW row -> out_proj;
  residual subtracts the masked reconstruction; output_proj over the sum
   |
   v
Decoder modules (mirror): transformers, then unpatch, then
de-interleave to (C, T)
```

## Verification

- **Fixture parity (tiny seeded tokenizer)**: encoder hidden states
  exact to 1e-6 relative, RVQ codes exact per book with normalized
  lookup margins, code length through the interleave/patch stack, and
  the decoded stereo waveform. Fixtures:
  `testdata/moss_audio_tokenizer/`, regenerated by
  `tools/gen_moss_fixtures.py` from the pinned commit.
- **Real checkpoint**: opt-in gate via
  `TURBOSPARK_MOSS_AUDIO_TOKENIZER_MODEL` (config.json +
  model.safetensors). Skipped when unset; not run on this machine.

## Scope and Divergences

- Batch `encode` / `decode` only; the streaming `step` path
  (`AttentionStepCache`) and batch>1 orchestration are not ported.
- The upstream `segment_size` chunking (6000 mel frames encode, 1500
  codec frames decode) is a memory optimization around identical
  per-segment math and is not reproduced; whole sequences are decoded
  in one call.
- Transformer `context` bands are computed from `context_duration`
  exactly like the reference constructor (frame rate starts at
  `sample_rate * channels` under interleave and tracks each module's
  downsample ratio).

## Parameters (default config)

| Parameter | Value |
|---|---|
| Sample rate | 48 000 Hz, 2 channels interleaved |
| Downsample rate | 3840 samples/token |
| Quantizer | 32 books x 1024 codes, codebook dim 32 (RLFQ) |
| Encoder/decoder | config-driven module stacks (patch + transformer) |
