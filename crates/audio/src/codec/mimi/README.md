# Mimi (Kyutai Neural Audio Codec)

Mimi is Kyutai's audio tokenizer for the Moshi speech model: a causal
SEANet encoder/decoder, a split residual vector quantizer (one semantic
codebook plus a 31-level acoustic stack), learned downsample/upsample
convolutions bridging the transformer frame rate, and a norm-first
RoPE transformer with a bounded causal context on each side.

## Model Overview

```text
Mono PCM (B, C, T) NCL
   |
   v
SeanetEncoder: WN-free convs with causal pad (constant mode), ELU,
   residual blocks (true_skip) with dilation base 2, strided downsample
   convs per ratio [8, 6, 5, 4]; 24 kHz -> 25 fps frames
   |
   v
EncoderTransformer: 8 layers, norm-first LayerNorm (eps 1e-5),
   packed-qkv attention (no bias), traditional (interleaved) RoPE,
   causal with context 250, tanh-GELU MLP (no bias), layer scale 0.01
   |
   v
ConvDownsample1d (stride 2, edge pad): 25 fps -> 12.5 fps
   |
   v
SplitResidualVectorQuantizer:
   rvq_first: in_proj (1x1 conv, no bias) -> 1 Euclidean codebook
      (2048 bins x 256 dims; embedding = embedding_sum /
      max(cluster_usage, 1e-5); argmin of ||emb||^2/2 - dot)
   rvq_rest: same projection -> 31-level residual stack on the same
      input (transcribed as-is; the rest does not consume the first's
      residual)
   |
   v  codes (B, 32, T)
decode mirrors: upsample -> decoder transformer -> SEANet decoder
```

### Architecture Specifications

| Property | Value |
|---|---|
| Sample rate / frame rate | 24 kHz / 12.5 fps (hop 1920) |
| SEANet | dim 512, filters 64, ratios [8, 6, 5, 4], k7, residual k3, last k3, compress 2, true_skip |
| Transformers | 2 x 8 layers, d_model 512, 8 heads, ff 2048, context 250, RoPE base 10000 |
| Quantizer | 32 codebooks, 2048 bins, 256 dims |
| Batch | 1 (crate convention) |

## Verification

Fixtures: `testdata/mimi/`, regenerated by `tools/gen_mimi_fixtures.py`
(run from the `../mlx-audio` checkout root with the project venv
interpreter). The tiny fixture seeds every parameter (including the
zero-initialized LSTM-free transformer and the codebooks) and refreshes
the derived state (`EuclideanCodebook._embedding`, the depthwise
upsample convtr) exactly as `load_pytorch_weights` does.

- Codes at all 32 levels are exact-equality gates protected by recorded
  first-codebook half-norm distance margins; decode waveforms and the
  isolated transformer trace are float-tolerant gates.
- The batch `encode` / `decode` paths are the reference's streaming
  paths with fully reset state, so batch parity pins the reset-state
  streaming contract.
- `cargo test -p turbospark-audio --lib codec::mimi` (4 tests).

## Real-checkpoint gate

Point `TURBOSPARK_MIMI_MODEL` at the kyutai tokenizer safetensors to
exercise the loader wiring on the full 512-dim model (finite, bounded
decode); it skips when unset. A full fixture golden from the real
checkpoint (with the PyTorch name mapping exercised) is still owed
before any quality claim.

## Scope and Reference Deviations

1. **Batch paths only.** `encode_step` / `decode_step` (conv ring
   buffers, KV caches, the StreamingAdd rebalancing) are not ported;
   the batch paths run the identical layer stacks over full sequences.
2. **Name mapping.** The Rust loader accepts both the post-mapping MLX
   names (fixture layout) and applies the reference's PyTorch rename
   rules for real checkpoints.
3. **MLX nn.RoPE(traditional=True)** is reproduced with interleaved
   pairs and per-pair frequencies `base^(-2i/d)`; MLX's rope applies to
   the full head dim.
