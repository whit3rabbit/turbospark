# EnCodec (SEANet-based Streaming Neural Audio Codec)

EnCodec is a high-fidelity neural audio codec developed by Meta (Defossez
et al.) and ported to Apple Silicon / MLX by mlx-audio. It features a
SEANet convolutional encoder/decoder architecture, a two-layer LSTM with
residual skip connections, and a multi-bandwidth residual vector quantizer
(RVQ).

## Upstream References and URLs

- **Reference implementation**: [`mlx_audio/codec/models/encodec/`](https://github.com/Blaizzy/mlx-audio/tree/e1b19b9054bf163f5d812221a54fcc346f1890e9/mlx_audio/codec/models/encodec)
  (encodec.py) at mlx-audio `e1b19b9054bf163f5d812221a54fcc346f1890e9`.
- **Deployed MLX checkpoint**: [mlx-community/encodec-24khz](https://huggingface.co/mlx-community/encodec-24khz)
- **Original paper**: "High Fidelity Neural Audio Compression" (Defossez et al., 2022).

## Model Overview

```text
Mono PCM
   |
   v
Causal Conv1d(1 -> num_filters, k7) with padding
   |
   v
[EncoderBlock x |upsampling_ratios|]
   Each: ResNet units (compress bottleneck, 1x1 shortcut) + strided conv
   |
   v
Two-layer LSTM with residual connection
   |
   v
Causal Conv1d(k7) -> latent frames
   |
   v
Residual Vector Quantizer (RVQ):
   Target bandwidth selects number of active codebook levels
   Level 0..K-1: Euclidean nearest codebook entry -> residual subtract
   |
   v  discrete codes: [num_levels, num_frames]
Decoder:
   Sum of per-level codebook lookups
   |
   v
Two-layer LSTM with residual connection
   |
   v
[DecoderBlock x |upsampling_ratios|]
   Transposed conv upsampling + ResNet units
   |
   v
Causal Conv1d(k7) -> reconstructed waveform
```

### Architecture Specifications

| Property | Value |
|---|---|
| Deployed checkpoint | mlx-community/encodec-24khz |
| Sample rate | 24 kHz (checkpoint); 48 kHz supported by architecture |
| Audio channels | Mono (1 channel) |
| Latent hop length | 320 (for [8, 5, 4, 2] strides), 75 fps at 24 kHz |
| Bandwidths | [1.5, 3.0, 6.0, 12.0, 24.0] kbps |
| Codebooks | 32 levels x 1024 entries x 128 dims |
| Normalization | weight_norm on all convolutions |
