# Descript Audio Codec (DAC)

Descript Audio Codec (DAC) is a high-fidelity universal neural audio codec
developed by Descript (Kumar et al.) and ported to Apple Silicon / MLX
by mlx-audio. It uses Snake activations, residual convolution units with
dilations 1, 3, and 9, and a residual vector quantizer (RVQ) with L2-normalized
codebook embeddings. DAC serves as the acoustic tokenizer and neural vocoder
for multiple voice and music generation models (e.g. Zonos, VoxCPM, Chatterbox).

## Model Overview

```text
Mono PCM
   |
   v
WnConv1d(1 -> encoder_dim, k7)
   |
   v
[EncoderBlock x |encoder_rates|]
   Each: ResidualUnit (dilations 1, 3, 9) with Snake activation + strided WnConv1d
   |
   v
WnConv1d -> latent frames [latent_dim, num_frames]
   |
   v
Residual Vector Quantizer:
   N codebook levels (each L2-normalized 1024 entries x 8 dims)
   |
   v  codes: [num_codebooks, num_frames]
Decoder:
   Sum of per-level codebook lookups -> out_proj
   |
   v
[DecoderBlock x |decoder_rates|]
   Transposed WnConv upsampling + ResidualUnit (dilations 1, 3, 9)
   |
   v
Snake + WnConv1d(k7) -> tanh -> reconstructed waveform
```

### Architecture Specifications

| Property | Value |
|---|---|
| Sample rate | 16 kHz, 24 kHz, or 44.1 kHz depending on checkpoint |
| Strides | [2, 4, 8, 8] (44.1 kHz) or [2, 4, 8, 8] / [8, 5, 4, 2] |
| Codebooks | Up to 32 levels x 1024 entries x 8 dims |
| Activations | Snake with learned alpha parameter |
| Normalization | weight_norm on all convolutions |
