# ECAPA-TDNN (Emphasized Channel Attention, Propagation and Aggregation TDNN)

ECAPA-TDNN is an acoustic embedding model designed for speaker identification
and verification. It incorporates squeeze-and-excitation (SE) residual
convolutions (Res2Net), multi-layer feature aggregation (MFA), and attentive
statistics pooling (ASP).

## Model Overview

```text
Mel Filterbank Features [80, num_frames]
   |
   v
TDNN Conv1d Stem (k5, dilation 1) + BatchNorm + ReLU
   |
   v
Three SE-Res2Net Blocks with Squeeze-and-Excitation:
   Block 1: kernel 3, dilation 2
   Block 2: kernel 3, dilation 3
   Block 3: kernel 3, dilation 4
   |
   v
Multi-Layer Feature Aggregation (MFA):
   Concatenation of stem and block outputs -> 1x1 Conv
   |
   v
Attentive Statistics Pooling (ASP):
   Self-attention weights -> weighted mean + weighted standard deviation
   |
   v
Dense Linear + BatchNorm -> 192-dimensional Speaker Embedding
```

### Architecture Specifications

| Property | Value |
|---|---|
| Input features | 80-channel log mel filterbank |
| Intermediate channels | 512 or 1024 (config-driven) |
| Output embedding | 192 dimensions |
| Res2Net scale | 8 sub-bands |
| Squeeze-and-Excitation | 128 bottleneck channels |
| Attentive pooling | Attentive mean + std concatenation |
