# MiMo Audio Tokenizer

The offline XiaomiMiMo MiMo-Audio-Tokenizer: a whisper-shaped mel
encoder with pre-norm transformer layers (RoPE attention, optional
causality and band masks), a 20-book Euclidean RVQ with per-book
sizes, and a mirrored decoder with GroupNorm-affined causal transposed
convs feeding a Vocos-style transformer and a magnitude/phase iSTFT
head. 24 kHz, 128 mel bands at 100 fps, 25 tokens/s.

## Model Overview

```text
Mono 24 kHz -> log-mel: periodic Hann(960), center/reflect STFT at
hop 240, magnitude HTK mel (no norm), log(max(., 1e-7))  (frames, 128)
   |
   v
Encoder: conv(k3, pad 1) + GELU -> conv(k3, stride 2, pad 1) + GELU
  -> trim to the valid length -> 32 pre-norm transformer layers
  (RoPE NeoX attention, skip connection from layer 3) -> LayerNorm
  -> avg-pooler: repeat last valid frame over conv padding, zero-pad
     to a pool multiple, strided conv(k2 s2) + GELU + LayerNorm
   |
   v
RVQ: 20 codebooks (1024, 1024, then 18 x 128) x dim 1280;
  distance = |w|^2 - 2 x.w (constant input norm omitted), argmin,
  residual subtraction; decode sums the embedding rows
   |
   v
Decoder: causal ConvTranspose(k2 s2) + GroupNorm(1) -> 32 causal
  transformer layers -> LayerNorm -> causal ConvTranspose(k3 s2)
  + GroupNorm(1), tail trim -> Vocos: mel embedding (bias-free) ->
  16 windowed transformer layers (band mask [-40, +10]) ->
  Linear to nfft + 2 -> magnitude = min(exp(m), 100), phase ->
  iSTFT (squared-Hann OLA denominator, trim (nfft - hop) / 2)
```

## Verification

- **Fixture parity (tiny seeded tokenizer)**: the HTK log-mel front
  end, encoder hidden states, RVQ codes (exact, with margins), and the
  full codes-to-waveform decode. Fixtures:
  `testdata/mimo_audio_tokenizer/`, regenerated by
  `tools/gen_mimo_fixtures.py` from the pinned commit (the dataclass
  config is fully data-driven, so the tiny geometry is a plain config
  with `weights_format=mlx`).
- **Real checkpoint**: opt-in gate via
  `TURBOSPARK_MIMO_AUDIO_TOKENIZER_MODEL` (config.json +
  model.safetensors). Skipped when unset; not run on this machine.

## Scope and Divergences

- Batch-of-one `encode_mels` / `decode`. The upstream `segment_size`
  chunking (6000 mel frames encode, 1500 codec frames decode) is a
  memory optimization around identical per-segment math and is not
  reproduced.
- The `istft.window` tensor registered in the MLX parameter tree is
  the authoritative synthesis window and is loaded when present; the
  periodic Hann derivation is the fallback. The STFT analysis window
  is always the derived periodic Hann (audio.py builds it fresh).
- RMSNorm (`ln_type="RMSNorm"`) is supported via config alongside the
  default LayerNorm.

## Parameters (default config)

| Parameter | Value |
|---|---|
| Sample rate | 24 000 Hz |
| STFT | nfft 960, hop 240, window 960 periodic Hann |
| Encoder | 32 layers, dim 1280, 20 heads, skip layer 3, pooler 2 |
| Decoder | 32 causal layers + 16 vocoder layers (dim 256) |
| Quantizer | 20 books: 2 x 1024 + 18 x 128, dim 1280 |
| Token rate | hop 240 x stride 2 x pooler 2 = 960 samples (25/s) |
