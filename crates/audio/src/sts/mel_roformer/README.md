# Mel-Band RoFormer (music/vocal source separation)

## Overview

Stereo 44.1 kHz source separation: symmetric-Hann STFT (center, reflect),
channel-interleaved (CaC) spectrum, binarized Slaney mel band split,
dual-axis (time/frequency) RoFormer transformers with interleaved RoPE and
per-head sigmoid gates, per-band GLU mask estimation, scatter-merge with
overlap averaging, complex masking, and overlap-add iSTFT. Ported from
`mlx_audio/sts/models/mel_roformer` (reference commit
`e1b19b9054bf163f5d812221a54fcc346f1890e9`, mlx 0.32.3).

## Architecture

- STFT: n_fft 2048, hop 441 (real presets), periodic (symmetric) Hann,
  center=True reflect padding, frames = 1 + samples / hop.
- CaC interleave: spectrum bin b of channel c maps to entry 2b + c with
  (real, imag) as the last axis.
- Band split: ZFTurbo binarized Slaney mel filterbank (60 bands at
  n_fft 2048), DC bin forced into band 0 and Nyquist into the last band;
  per band the CaC gather is flattened to (entry, re/im) pairs,
  F-normalize RMSNorm, then a linear projection to the model dim.
- Transformer: pre-RMSNorm (F.normalize: x / max(norm, 1e-12) * sqrt(dim)
  * gamma), multi-head attention with interleaved-pair RoPE (frequencies
  duplicated [f0, f0, f1, f1, ...], base 10000), scaled dot-product
  (1/sqrt(dim_head)), per-head sigmoid gates from a biased linear,
  output projection (no bias); FFN is RMSNorm -> linear -> exact erf
  GELU -> linear (biased); residual adds; final F-normalize RMSNorm per
  axis. Depth x (time-axis over frames, freq-axis over bands).
- Mask estimation: per band MLP, Linear(dim -> 4*dim) -> tanh ->
  (depth-1) x [Linear(4*dim -> 4*dim) -> tanh] -> Linear(4*dim ->
  2*band_dim) -> GLU (first half * sigmoid(second half)).
- Merge: scatter per band into the CaC spectrum and divide by the
  per-bin overlap count (floor 1).
- Synthesis: complex multiply, de-interleave, iSTFT with window-squared
  (COLA) normalization and the center pad stripped, trimmed/padded to
  the input length.

## Checkpoint notes

- Config presets: kim_vocal_2 (depth 6, 228M params), viperx_vocals and
  zfturbo_bs_roformer (depth 12), zfturbo_vocals_v1 (dim 192, depth 8,
  hop 512, mask_estimator_depth 1). The reference refuses to guess a
  config; `MelRoFormer::open` does the same and requires config.json.
- Weights must be in the MLX post-sanitize layout (separate to_q/to_k/
  to_v, `.gamma` renamed to `.weight`, mask-MLP Sequential indices
  remapped). Packed `to_qkv` keys are refused with a pointer to the
  reference `sanitize`/convert step.
- `chunk_size`/`num_overlap` are caller-level streaming parameters in
  the reference; this port is single-pass like the reference `__call__`.

## Documented divergences

- f32 radix-2 FFT here vs MLX's own f32 FFT; stage diffs above quantify
  the residue. The Slaney filterbank is binarized (support-only), so
  area-norm differences do not affect band assignment.
- Batch is fixed at 1 (single stereo item), matching the reference
  pipeline's intended use.
