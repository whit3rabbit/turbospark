# SAM-Audio (text-guided source separation)

## Overview

Text-prompted separation of a target sound from its background: a DACVAE
codec lifts the waveform to codebook-space means; a T5 encoder embeds the
description; a DiT with adaLN timestep modulation, QK-normed attention
(SAM-Audio's head-dim-major reshape), adjacent-pair RoPE, and
cross-attention to the projected text memory predicts a velocity field; a
midpoint ODE integrates noise into separated target/residual features
that the codec decodes back to waveforms. Ported from
`mlx_audio/sts/models/sam_audio` (reference commit
`e1b19b9054bf163f5d812221a54fcc346f1890e9`, mlx 0.32.3).

## URLs

- Upstream model: https://github.com/facebookresearch/sam-audio
- Reference implementation: `mlx_audio/sts/models/sam_audio/` in the
  pinned checkout at `../mlx-audio`
- Checkpoint: https://huggingface.co/mlx-community/sam-audio-large

## Architecture

- Codec: DACVAE codebook-space means (in_channels = 6 * codebook_dim =
  768 on real presets; out_channels = 2 * codebook_dim = 256), doubled
  per frame for target+residual. The crate's existing `codec::dacvae`
  provides encode/decode.
- T5 encoder (encoder stack only): shared embedding, per-block RMS
  layer norms (no mean subtraction, eps 1e-6), bidirectional relative
  position buckets (32 buckets, max distance 128, block 0 carries the
  table), no attention scaling, gated GELU (exact erf) feed-forward.
- DiT: patcher ResnetBlock (GroupNorm with 1 group, SiLU, Conv1d k=3
  pad 1, identity residual), sinusoidal timestep embedding
  (transformer.dim wide at the model level, frequency_embedding_dim at
  the embedder) through a SwiGLU projection and a silu+linear
  t-block producing 6*dim adaLN parameters, context SwiGLU embedder,
  blocks of [adaLN-modulated self-attention with RoPE, cross-attention
  to text memory, adaLN-modulated SwiGLU FFN], final table modulation.
- Attention: the projection output is read head-dim-major
  ((T, head_dim, heads), so head h takes strided features), QK RMSNorm
  (eps 1e-5), adjacent-pair RoPE (theta = max(10000, 2 * max_positions),
  self-attention only), learned per-head sigmoid gates are NOT part of
  this model (that is Mel-Band RoFormer), key padding masks as -inf.
- ODE: midpoint by default (2 evaluations per step), step_size 2/32
  (16 steps), integrated from t=0 to t=1 over the feature sequence.

## Checkpoint notes

- Real presets: small/base/large differ in DiT dim/heads/layers
  (1024/8/12, 1536/12/16, 2816/22/22); T5 is t5-base (768/12/12).
- The Rust API takes T5 token ids and an attention mask; the
  sentencepiece tokenizer is a runtime/catalog concern (matching the
  reference, which loads tokenizer and T5 weights from HuggingFace
  separately from the separation checkpoint).
- The fixture splits the DACVAE subtree into a separate bare-key
  safetensors file (`tiny_codec.safetensors`) consumed by the existing
  crate loader; the real checkpoint keeps one file with an
  `audio_codec.` prefix, which the runtime layer must split out.
- PyTorch-converted checkpoints must pass the reference `sanitize`
  (LSTM bias merge, key renames) first; the loader expects the MLX
  post-sanitize key tree.
- Temporal anchors are implemented (`EmbedAnchors`: embed, gate,
  projection, alignment-indexed) and pinned by the velocity fixture.

## Documented divergences

- f32 radix-2 FFT in the codec vs MLX's own FFT; stage diffs above.
- Batch size 1 (the reference pipeline is per-item; mixed text/audio
  batch sizes raise in the reference and are not supported here).
- The fixture `config.json` carries a `t5_arch` section with the tiny
  T5 geometry; the reference derives T5 shape from the HuggingFace
  t5-base config at load time instead.
