# DialogueSidon (two-speaker separation / restoration)

## Overview

Offline two-speaker separation and degraded-speech restoration at 24 kHz:
Kaldi-style 80-mel features feed a w2v-BERT-style encoder (relative-position
attention, causal GLU convolution module); two projection heads form a
conditioning vector; an adaLN diffusion transformer with half-split RoPE
samples two latent tracks through a second-order DPM-Solver++ (v-prediction);
a DAC decoder renders the speakers. Ported from
`mlx_audio/sts/models/dialogue_sidon` (reference commit
`e1b19b9054bf163f5d812221a54fcc346f1890e9`, mlx 0.32.3).

Measured parity, Rust vs the Python reference (2026-10-07,
`cargo test -p turbospark-audio --lib dialogue_sidon`):

| Stage | Max abs diff |
|---|---|
| Frontend features [38, 160] | 1.5e-4 |
| Encoder, linear1/2, conditioning | 4.5e-8 |

| Sampled latents (8 DPM steps) | 1.8e-3 |
| Decoded speakers | 4.0e-2 on 0.057 peak |

The prediction-to-speakers growth is summation-order noise amplified by
the solver and the six-stage transposed-convolution decode; every probed
sub-stage (projections, adaLN, RoPE, attention inputs) matches to 1e-7
and the attention output to 6e-5. Not yet verified: real-checkpoint gate
(1.78 GB fp32 / 889 MB bf16), restoration quality, chunked stitching
against the reference, Metal offload, runtime, catalog, FFI, Swift gates.

## Architecture

- Frontend: 400/160 framing at 16 kHz, per-frame DC removal,
  pre-emphasis 0.97 (first tap scaled 0.03), povey window
  (0.5 - 0.5 cos)^(0.85), 512-point power spectrum, torchaudio Kaldi
  80-mel bank (257 bins padded to 258), log floor 2^-23, per-bin
  variance normalization across frames (ddof=1, eps 1e-5), odd-frame
  zero-pad; adjacent 80-dim frames pair into 160-wide tokens and the
  mask keeps every second frame (mask[1::2]). Peak normalization to
  0.9 with 160-sample pads precedes feature extraction.
- Encoder: feature LayerNorm+linear; per layer: half-weight FFN
  residual, relative-position attention (distance table clamped to
  [-64, 8], bias q @ table^T gathered per pair, head_dim^-0.5 scaled,
  additive mask), convolution module (LayerNorm, pointwise 1x1 to
  2C, GLU, causal depthwise k=31, LayerNorm, SiLU, pointwise 1x1),
  second half-weight FFN, per-layer final LayerNorm.
- Diffusion: sinusoidal timestep embedding through a two-layer MLP;
  per block: adaLN (SiLU -> linear to 6x dim: shift/scale/gate for
  attention and FFN), affine-free LayerNorm, standard attention with
  half-split RoPE (base 10000) on q/k, exact-erf GELU FFN; final
  adaLN layer with a bias-free linear to 2 * latent_dim.
- Sampler: linear beta schedule (1e-4 to 0.02 over 1000 steps),
  f64 cumulative products, linspace timesteps rounded and reversed,
  DPM-Solver++ second order with v-prediction; per-call state.
- Decoder: the standalone DAC decoder (crate `codec::descript`),
  consuming `[latent, frames]` channel-major latents per speaker.

## Checkpoint notes

- Real model: encoder hidden 1024 (16 heads, 13 layers), diffusion
  hidden 768 (12 heads, 8 layers), latent_dim 32, decoder 1536 with
  rates [8, 5, 4, 3]. Config may carry latent normalization statistics.
- The checkpoint directory supplies the model weights
  (`model.safetensors`, keys under `encoder.*`, `linear1/2`,
  `diffusion_head.*`, `decoder.*`) and a separate DAC tree for the
  crate loader (`dac_config.json` + `dac.safetensors`); the decoder
  subtree of the model file carries the separation decoder weights.
- Chunked long-file inference (20 s chunks, 5 s overlap) with the
  reference's correlation-based speaker alignment and linear crossfade
  is part of the reference `separate()`; the fixture pins the
  whole-file path.

## Documented divergences

- f32 radix-2 FFT and plain-loop softmax/attention summation order;
  stage diffs above quantify the residue through the solver and decode.
- Batch is fixed at 1.
