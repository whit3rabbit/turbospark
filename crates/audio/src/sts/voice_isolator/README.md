# Inworld Voice Isolator v1

Keeps the voice in a recording and removes everything else: noise, music,
reverb tails, a quieter competing talker. 48 kHz mono in and out.

## Upstream

- Checkpoints: https://huggingface.co/inworld/voice-isolator at

## Architecture

STFT n_fft 2048, hop 480 (10 ms), periodic Hann, center with reflect
padding. The 1025 bins are cut into 46 bands (`band_plan`), each band a
token of width 512 after a per-band LayerNorm and Linear plus a learned band
embedding (and, for the realtime file, a look-ahead position embedding).
Seven dual-path blocks alternate:

- attention: time attention per band (RoPE over frames, exclusive self
  attention, pre-norm, GELU feed-forward), then attention across the bands
  of each frame;
- Mamba: a Mamba1 layer along time per band (bidirectional offline, forward
  only in the causal file), then a bidirectional Mamba1 across bands.

Per-band heads predict four values per bin: a complex mask `2 tanh(.)` and
a residual bounded by `0.5 |X|`. The output is the input plus the iSTFT of
`X * mask + residual`. The architecture is read from the checkpoint's
safetensors metadata (`config`); anything this port does not implement
(dual mode, mode FiLM, other decoders) is refused, and so is a checkpoint
carrying weights the network never reads.

Offline renders use the checkpoint's window (8 s, 2 s linear crossfade,
the last window ending at the clip's end). The realtime file streams
(`stream.rs`): a frame is computed as soon as its analysis window is
complete, attention keeps a cache of rotated keys bounded by the trained
1200-frame window, the time Mamba carries its conv and scan state, and the
decoder output for frame t is read at t + look-ahead (0, 2 or 4 frames;
default 2, 63 ms algorithmic latency).

## Verified

Fixtures: `testdata/voice_isolator/{offline,causal}`, seeded tiny networks
with every parameter randomized, regenerated by
`tools/gen_voice_isolator_fixtures.py <reference checkout>` with
`../.venv-mlxaudio` (torch 2.12).

| Check | Max abs diff |
|---|---|
| STFT, encoders, every block, decoder (each fed the reference's input) | <= 1.7e-5 |
| Forward and chunked render (4 windows) | 1.2e-7 |
| Each trained look-ahead (0, 2, 4) | 6e-8 |
| Stream on ragged pushes against `streaming.Stream` | 9e-8 |
| Stream independent of push sizes and block size | < 1e-5 |

Real checkpoints against the torch CPU reference
(`tools/gen_voice_isolator_real_reference.py`), 10 s of LibriSpeech speech
plus white noise at 0 dB, `TURBOSPARK_VOICE_ISOLATOR_MODEL=~/models/voice-isolator`:
offline 2.7e-7, realtime 2.2e-7.

The one reference detail the first port missed: torch.istft's irfft ignores
the imaginary part of the DC and Nyquist bins, which the correction gives
an imaginary part. Keeping them moved the output by 4e-3.

## Speed (M4 Max, AC power, one run each, not benchmark rows)

| Path | Offline file, 10 s | Realtime file, 10 s | Realtime stream, 20 ms pushes |
|---|---|---|---|
| CPU f32 | 21.3 s | 12.6 s | not measured |
| Metal projections, attention, scan (`runtime::voice_isolator`) | 14.2 s | 8.3 s | RTF 3.0 to 3.9 |

The Metal path is per-call: each projection uploads its input and reads its
output back, and a 20 ms stream push makes about 74 such calls, so the stream
is not real time on it. The stateful Core ML step (`COREML.md`) runs a push
as one call: through `runtime::voice_isolator_live` on fp16 CPU and GPU, 500
pushes of 20 ms took a median 15.8 ms (p95 16.1 ms; one push over 20 ms, the
first, 194 ms), and its output sat 67.6 dB above its difference from the CPU
port stream (max abs 3.1e-4). The Neural Engine refuses the fp16 program, so
the host asks for CPU and GPU explicitly. The program is a local export (not
yet a pinned catalog asset): place `VoiceIsolatorStep.mlmodelc` beside
`denoiser_realtime.safetensors` and the live session takes it.
Quality beyond reference parity (PESQ/DNSMOS on real recordings) is not
measured here.
