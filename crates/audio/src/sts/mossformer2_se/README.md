# MossFormer2 SE 48K (speech enhancement)

## Overview

Full-band 48 kHz speech enhancement: a MossFormer MaskNet predicts a complex
STFT mask from Kaldi fbank + delta features, and the masked spectrum is
resynthesized with an overlap-add iSTFT. Ported from `mlx_audio/sts/models/
mossformer2_se` (normative reference commit
`e1b19b9054bf163f5d812221a54fcc346f1890e9`, mlx 0.32.3).

## URLs

- Checkpoint: https://huggingface.co/starkdmi/MossFormer2_SE_48K_MLX
  (fp32/fp16/int4/int6/int8 safetensors; no config.json in the repo)
- Upstream reference: `mlx_audio/sts/models/mossformer2_se/` in the pinned
  mlx-audio checkout at `../mlx-audio`
- Architecture origin: ClearerVoice-Studio MossFormer2
  (https://github.com/modelscope/ClearerVoice-Studio), paper
  "MossFormer2: Combining Transformer and Gated Convolution for Speech
  Separation" (https://arxiv.org/abs/2302.11824 successor, ICASSP 2024)

## Architecture

- Front end: Kaldi log-mel fbank (60 mels, hamming, preemphasis 0.97,
  win 1920 / hop 384 / FFT 2048 via next-power-of-2, snip_edges framing,
  DC removal per frame) + delta and delta-delta (win_length 5, edge pad)
  = 180 features; reference `compute_fbank_kaldi` / `compute_deltas_kaldi`.
- Mask net: GlobalLayerNorm -> 1x1 encoder conv (180->512) -> scaled
  sinusoidal position embedding -> 24 x [FLASH block, gated FSMN block]
  -> LayerNorm -> GroupNorm(1) + skip -> PReLU -> 1x1 speaker conv
  (512->1024) -> per-speaker tanh/sigmoid gate -> 1x1 decoder conv
  (512->961) -> ReLU; first speaker is the enhancement mask.
- FLASH block: token shift (first feature half delayed one frame),
  FFConvM projections (LayerNorm->linear->SiLU->depthwise conv k=17
  pad 8 + residual), OffsetScale heads (quad_q, lin_q, quad_k, lin_k),
  half-split RoPE over the first 32 of 128 qk dims (positions along
  time), group-of-256 attention: ReLU(qk^T/256)^2 @ v plus non-causal
  linear attention normalized by the unpadded length, gated by
  (att_u * v) * sigmoid(att_v * u), FFConvM output projection + residual.
- Gated FSMN block: 1x1 conv (512->256) -> PReLU -> CLayerNorm ->
  gated FSMN (two FFConvM branches with LayerNorm norm, UniDeepFsmn:
  linear->relu->project->depthwise 39-tap symmetric-pad time conv with
  both residuals) -> CLayerNorm -> 1x1 conv (256->512) + residual.
- Synthesis: Hamming-windowed STFT (center=False) masked, then iSTFT
  overlap-add normalized by the window-squared sum floored at 1e-10
  (`ISTFTCache.istft`).
- Enhance wrapper: full path below 20 s, segmented 4 s windows at 75 %
  stride discarding (window-stride)/2 edge samples at 20 s and above,
  chunked 4 s chunks at 25 % overlap above the 60 s threshold.

## Parameters and checkpoint notes

- Real checkpoint: 55.3M parameters; out_channels 512, num_blocks 24,
  query_key_dim 128, group_size 256, inner FSMN channels 256, lorder 20.
  The MaskNet `group_size` argument is dead in the reference; the
  MossFormerM defaults (256/128) are the only reachable geometry and are
  fixed constants here.
- Weight keys carry an optional leading `model.` component; both
  spellings (and the bare `mossformer.*` tree used by the tiny fixture)
  resolve.
- MLX conv layouts arrive as [out, kernel, in]; converted at load.
- Quantization: plain F32/F16 linears and 8-bit group-64 affine
  (U32-packed) are accepted. Other bit widths are refused, not silently
  mis-decoded. The upstream repo ships no config.json, so
  `MossFormer2Se::open` falls back to the reference defaults when the
  file is absent (the Python loader requires the file; we do not).

## Documented divergences

- Kaldi fbank dither defaults to 0 and nonzero values are refused: the
  reference default draws fresh `mx.random.normal` noise on every call,
  which makes the reference itself nondeterministic and un-parity-able.
  At the 32768-scaled input magnitudes the dither is ~-90 dBFS.
- Segmented and chunked reassembly follow the reference index math but
  are pinned by invariant tests (finite output, exact length) only; the
  full path carries fixture and real-checkpoint parity.
- f32 throughout; the reference computes on GPU f32 with fused MLX
  kernels. Stage diffs above quantify the residue.
