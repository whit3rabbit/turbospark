# Zonos v2 family (ZONOS2)

Rust-path port of `mlx_audio/tts/models/zonos2/` (model.py, config.py,
generation.py, prompt.py) at mlx-audio
[`e1b19b9054bf163f5d812221a54fcc346f1890e9`](https://github.com/Blaizzy/mlx-audio/tree/e1b19b9054bf163f5d812221a54fcc346f1890e9/mlx_audio/tts/models/zonos2)
(mlx 0.32.3): a custom decoder-only backbone over the delayed-audio
frame layout (`n_codebooks` audio embedders plus a text embedder,
summed per column) with gated attention (weightless q/k RMSNorm, the
learned per-head `temp` applied after the q norm, interleaved rope),
fused-residual RMSNorm blocks, dense or router-MoE SwitchGLU
feed-forward (router state thread, balancing biases, per-layer top-k
overrides), and a softcapped `multi_output` head producing
`n_codebooks x (codebook_size + 2)` logits per frame. Generation is
the 9+1-column delayed-frame loop (`audio_pad_id` padded prompts, the
text column carrying the byte-level ids and conditioning markers, an
EOS countdown of `n_codebooks + 1` frames after the max eoa codebook)
with the waveform decode through the shared Descript Audio Codec
44 kHz port ([codec README](../../codec/descript/README.md)).

Spec task: 78. Reference checkpoints: Zyphra/ZONOS2
(mlx-community/Zyphra-ZONOS2), DAC
mlx-community/descript-audio-codec-44khz, speaker encoder
marksverdhei/Qwen3-Voice-Embedding-12Hz-1.7B.

## Scope

- Batch size 1, non-streaming (`stream` chunking and `batch_generate`
  with `BatchKVCache` left padding stay open). The reference
  `generate` prefill plus per-frame loop is ported one-to-one.
- Text conditioning is the reference byte-level id encoding (`BOS`,
  utf-8 bytes + 192, `EOS`); the optional `TTSTextNormalizer` is a
  caller concern. Conditioning markers (speaking-rate bucket,
  per-feature quality buckets, speaker background clean/noisy,
  accurate mode) are ported exactly, including the vocabulary-base
  arithmetic and the marker-row layout (`audio_pad_id` columns plus
  the marker in the text column).
- Speaker conditioning takes a caller-supplied embedding vector
  injected at row 0 after the embedding sum (the reference
  `_inject_speaker` single-position path), through the optional LDA
  projection and `speaker_projection`. Extracting the embedding from
  reference audio needs the separate downloadable speaker encoder and
  stays open.
- Prompt tail is the fixed 17-frame sheared silence table
  (`_SILENCE_TOKENS_0_2S`) sliced to `n_codebooks`.
- Sampling: per-codebook repetition penalty over the generated frames
  (window `repetition_window`, codebooks limited by
  `repetition_codebooks`), temperature scaling, top-k on the scaled
  logits (ties survive, the reference `where(<)` rule), softmax, then
  top-p and min-p on the probabilities with renormalization, and the
  invalid-distribution fallback to the filtered-logit argmax. One
  `text_vocab` column is appended per frame. Sampled draws use the
  crate-local threefry RNG (one key per frame step), so a fixed seed
  fixes the Rust sequence; the reference draws through `mx.random`,
  which is not reproducible across engines (see
  [sampling](../sampling.rs)), so the fixtures pin the deterministic
  paths only.

## Layout

- `mod.rs`: the resolved config (`Zonos2Config.from_dict` with the
  nested `model` flattening, the derived intermediate size, the
  `quality_buckets` count derivation, and the MoE layer-range rules),
  the prompt math (`shear`, `shear_up`, `silence_prompt_tokens`,
  `text_to_byte_ids`, the conditioning id functions), the gated
  attention, the router (`Router` with the EDA state thread and
  balancing biases), the SwitchGLU MoE and dense paths, the fused
  residual norm, the sampler (`sample_frame`), the generation state,
  `generate`, and `decode_audio`.
- `tests.rs`: fixture parity and unit checks (eos countdown, ignore
  eos, byte ids, config/MoE layout, shear round trip).

## Verification

Fixtures: `testdata/tts_zonos2/`, regenerated by
`tools/gen_zonos2_fixtures.py` against the pinned commit (seeded, no
network; run from the mlx-audio checkout):

```sh
cd ../mlx-audio
../.venv-mlxaudio/bin/python \
    ../turbospark/crates/audio/tools/gen_zonos2_fixtures.py
```

The reference Model builds at tiny seeded dims (4 layers, dim 16,
head_dim 8, 1 kv head, 3 codebooks over codebook vocabulary 1024,
text_vocab 455, MoE layers 1-2 with the layer-2 top-2 override, 4
experts over router dim 8, speaker embedding dim 8 through an LDA
projection to 4) and a seeded tiny DAC (3 codebooks, hop 8). Weights
are stored F16 and the traces record the upcast F32 values the Rust
path reads. Coverage:

- Prompt rows over six conditioning combos, the shear/shear-up pair,
  the silence tail, and the byte ids: exact.
- Forward hidden states and softcapped logits for the plain and
  speaker-injected prompt prefills, 2e-4 absolute gate; the full
  21-row plain-prompt trace measured 5.96e-07 max absolute error at
  freeze.
- Greedy end-to-end scenarios (natural 24-frame run, the 4-frame
  max-tokens stop, speaker-conditioned, rate + quality conditioning):
  generated delayed frames and eos frame exact.
- The per-frame sampler on fixed logits: the temperature-0 argmax
  with the repetition penalty over a history, and the invalid-fallback
  greedy branch (min-p above 1), exact.
- The decode leg through the tiny DAC (shear up, eos trim, clip,
  decode, hop trim), 2e-4 absolute gate; measured 1.79e-07.

Fixture-generator note: `run_greedy` iterates
`params.max_tokens` (the reference generate loop bound). An earlier
revision looped the `MAX_TOKENS` default instead, which recorded a
24-frame table under the 4-token `max_tokens` scenario; the loop bound
was fixed and the fixtures regenerated (only that scenario changed;
every other digest is byte-identical).

Port notes (parity fixes made during verification, each localized
against per-stage reference traces):

- The learned per-head `temp` multiplies q AFTER the weightless q
  RMSNorm. Folding it into `wq` cancels: the norm is scale-invariant,
  so the fold is erased before it could act. The family owns its gated
  attention instead of the shared engine (the shared struct is
  constructed in files outside this family's scope) so the scale can
  sit between the norm and rope, and the attention output reorders
  head-major to token-major before the sigmoid gate and `wo` (the
  gate multiplies heads, matching the reference broadcast).
- The router selects top-k on the balanced scores
  `expert_prob + balancing_biases` (legacy) or
  `expert_prob - balancing_biases` (quantile), while the routing
  weights stay the raw probabilities of the picked experts. The
  checkpoint parameter is loaded (a fresh reference model saves zeros,
  and the fixture generator randomizes the parameter, so it is
  load-bearing for parity); the selection keeps ties to the lower
  expert, matching the top-1 argmax and the descending score sort.
- The SwitchGLU dispatch runs each (token, slot) pair in router
  ranking order (slot order is reduction order), matching the
  reference sum over the slot axis; the reference `_gather_sort` is a
  memory-access optimization that does not change per-token math.

`cargo test -p turbospark-audio --lib tts::zonos2` runs the family
gate.

## Open items

- Real-checkpoint gate: an end-to-end run on
  mlx-community/Zyphra-ZONOS2 (real dims, bundled 44 kHz DAC, quality
  and memory sanity against the Python family) has not been executed;
  the fixtures are seeded tiny instances.
- Streaming (`stream` with `streaming_interval` chunking) and
  `batch_generate` (batched prompts, `BatchKVCache` left padding, and
  per-sequence speaker positions) are unported.
- Speaker embedding extraction from reference audio needs the
  separate speaker encoder download (`Zonos2SpeakerEmbeddingExtractor`
  over marksverdhei/Qwen3-Voice-Embedding-12Hz-1.7B); callers supply
  the embedding vector until that lands.
- The quantile balancing strategy follows the reference sign flip but
  is unexercised by fixtures (the fixture config uses legacy).
- Sampled (temperature > 0) generation is not bit-reproducible
  against mlx by design; the filtered distributions are pinned by the
  sampling fixtures and the invalid fallback branch.
