# Spark-TTS 0.5B (BiCodec)

Rust-path port of `mlx_audio/tts/models/spark/` at mlx-audio
[`e1b19b9054bf163f5d812221a54fcc346f1890e9`](https://github.com/Blaizzy/mlx-audio/tree/e1b19b9054bf163f5d812221a54fcc346f1890e9/mlx_audio/tts/models/spark):
a qwen2 backbone (the shared [`crate::lm`](../../lm) port, dispatched
through `lm::qwen2::load` exactly like the reference model map) that
generates `<|bicodec_semantic_i|>` tokens over a task-qualified prompt,
with the waveform decode through the
[`spark_bicodec`](../../codec/spark_bicodec) decoder.

Spec task: 28. Reference checkpoints: mlx-community/Spark-TTS-0.5B.

## Scope

- Batch size 1, non-streaming (the reference loops `stream_generate`
  per text split; segment splitting stays with the caller).
- Prompt construction is string-level and tokenization is caller-owned:
  the reference encodes the prompt string with the bundled fast
  tokenizer (every `<|bicodec_semantic_i|>`-style marker is one token).
  [`AudioTokenMaps`] carries the marker-to-id lookup and the reverse
  extraction the reference regex performs.
- The generate loop mirrors `stream_generate` + the reference generate:
  prefill of every prompt token but the last, the
  `make_logits_processors` chain (logit bias, then the sign-aware
  repetition penalty, defaults 1.3 over a 20-token context that
  accumulates the last prompt token plus every generated id), the
  log-softmax, and the `make_sampler` chain (top-p 0.95, then top-k 50,
  then the categorical draw; temperature 0 is exact argmax). Stops: the
  config `eos_token_id` (the stream breaks without yielding it), the
  hard-coded semantic-end token 128258 (appended before the break), or
  the `max_tokens` budget (default 3000).
- Sampling draws use the crate-local threefry RNG, so a fixed seed
  fixes the Rust sequence; the filtered distribution is pinned against
  Python. Temperature 0 runs never draw.

## Verification

Fixtures: `testdata/tts_spark/`, regenerated by
`tools/gen_spark_fixtures.py` against the pinned commit (seeded, no
network; the reference Model built at 2 layers, hidden 32, vocab 512
with the tied head, and the bundled tokenizer replaced by a
deterministic mock that assigns fixed ids to every special marker).
Coverage:

- Greedy end-to-end scenarios (semantic-end stop, eos stop with no
  tokens, max-tokens stop): sampled ids, extracted semantic and global
  codes, and stop reasons all exact against the reference loop.
- The sampler chain on fixed logits: logit bias, the truncated-context
  repetition penalty, the log-softmax, and the top-p/top-k filtered
  distributions (masked lanes as nulls), 1e-5 absolute.
- The `process_prompt` / `process_prompt_control` strings and the
  gender/pitch/speed map validation errors.
- Config parsing through `Model::open` on both fixture checkpoints
  (base and eos-first).

Real-checkpoint gate (parity + quality on mlx-community/Spark-TTS-0.5B)
NOT run; open item. Fixture weights are F16-stored and the live traces
compute on the upcast F32 values.

## Open items

- Voice-clone token extraction: `process_prompt` needs
  `BiCodecTokenizer.tokenize(ref_audio)`, which runs
  wav2vec2-large-xlsr-53 features (hidden layers 11 + 14 + 16 over 3)
  plus the BiCodec encode direction (encoder, factorized-quantizer
  argmin, ECAPA + Perceiver + FSQ speaker tokenize). Callers supply the
  reference global/semantic codes directly until that lands; the
  controllable path (gender/pitch/speed) is fully closed.
- The waveform decode is `BiCodec::detokenize` (see the
  [codec README](../../codec/spark_bicodec)); on the control path the
  global codes come from the generated ids, on the clone path from the
  reference audio.
- Sampled-draw parity with `mx.random` is intentionally not attempted
  (see [sampling](../sampling.rs) docs).
