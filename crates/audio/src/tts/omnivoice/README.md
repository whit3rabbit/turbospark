# OmniVoice

Port of the mlx-audio OmniVoice family at
[`e1b19b9054bf163f5d812221a54fcc346f1890e9`](https://github.com/Blaizzy/mlx-audio/tree/e1b19b9054bf163f5d812221a54fcc346f1890e9/mlx_audio/tts/models/omnivoice):
zero-shot multilingual TTS over a bidirectional Qwen3 backbone with
iterative masked-diffusion decoding (non-autoregressive) of 8
HiggsAudioV2 codebooks (vocab 1025 including the mask token at 1024,
24 kHz, `sample_rate / 960` tokens per second).

## Layout

- `mod.rs` (one file):
  - `OmniVoiceConfig` over the checkpoint `config.json` (the
    `llm_config` dict parses through the shared qwen3 engine config);
  - `combine_text` / `build_style_text` / `build_wrapped_text` - the
    reference string rules (ref-transcript join, newline removal,
    space/tab run collapse, CJK-adjacent whitespace removal, the
    `<|denoise|>` / `<|lang_*|>` / `<|instruct_*|>` / `<|text_*|>`
    wrappers); tokenization is caller-owned;
  - the bidirectional backbone through [`crate::lm`] qwen3 with the
    causal mask disabled (`Backbone::set_bidirectional`), 8 audio
    embedding tables summed per frame against the first-column text
    embedding, and 8 prediction heads stacked per position;
  - `prepare_inference_inputs` (the `[style | text | ref | target]` id
    grid with the audio mask over `[ref | target]`) and
    `iterative_unmask`: the cosine-shifted schedule
    (`t' = t_shift * t / (1 + (t_shift - 1) * t)`), per-step CFG over
    the conditional and target-only unconditional passes
    (`log_softmax(c + g * (c - u))`), the mask-token column suppressed
    to -inf, greedy argmax at temperature 0 (top-ratio filter plus a
    Gumbel perturbation above it), the layer-penalized confidence
    (`max_log_prob - layer_id * penalty`, the penalty following each
    cell's COLUMN), the Gumbel position noise, and the argsort-rank
    reveal of the k best-scoring still-masked cells with
    `k = ceil(total_mask * dt)` (the last step reveals everything);
  - `generate`: assemble, unmask, then decode through the shared
    [`codec::higgs_audio`](../../../codec/higgs_audio) port.

## Reference quirks kept

- text token ids broadcast across every codebook column; the audio mask
  covers exactly the `[ref | target]` rows;
- the unconditional pass drops the `[style | text]` prefix and keeps
  the target block only;
- the mask-token suppression happens after the CFG combine, so the
  combined softmax never sees the mask column as -inf;
- the confidence penalty follows each cell's codebook column (the
  reference subtracts `layer_ids * factor` broadcast over `[T, C]`);
- surviving mask tokens are replaced with codec token 0 before decode;
- voice cloning prepends `<|denoise|>` to the style prefix; the
  reference-audio preprocessing plus codec encode
  (`create_voice_clone_prompt`) is the codec family's encode path and is
  caller-owned here (pass `ref_tokens`).

## Deviations

- single batch (the reference `generate_batch` packing is not ported);
- non-streaming;
- text tokenization and the reference-audio encode are caller-owned
  intake (documented sweep choice);
- the Gumbel-uniform stream is caller-supplied for fixture replay or
  derived from the crate-local threefry RNG; it is not bit-reproducible
  against `mx.random` (documented sweep choice). The fixture pins the
  replayed `mx.random` stream, so the verified trajectory is exact.
- `class_temperature > 0` is ported (top-ratio filter + Gumbel over the
  token axis) but only the temperature-0 greedy path is
  fixture-verified.

## Verification

Fixtures at `crates/audio/testdata/tts_omnivoice/`, regenerated by
`tools/gen_omnivoice_fixtures.py` (run from the mlx-audio checkout with
the project venv; deterministic seeds, no network). The generator runs
the true reference `iterative_unmask` on a tiny seeded instance
(qwen3 at hidden 32 / 2 layers / 4 heads / 2 kv heads / tied embeddings,
text vocab 128, 8 audio codebooks of vocab 17 with the mask at 16) with
`num_steps 4`, `guidance_scale 2.0`, `class_temperature 0`,
`position_temperature 5.0`, `layer_penalty_factor 5.0`, `t_shift 0.1`,
over two cases (`plain`, `voice_clone` with a 4-frame reference block).
The position-Gumbel uniforms are recorded from the seeded `mx.random`
stream and replayed by the Rust. The tiny codec (8 RVQ books, latent 8,
decoder input 6 - the codec family fixture geometry) provides the
`tokenizer.decode` stack, and the recorded waveform stays unclipped.

Measured parity on the frozen fixtures: the assembled id grids and
audio masks exact; final token grids exact for both cases; the decoded
waveform 5.6e-9 absolute against a 1e-5 gate.

Mutation notes from bring-up (each was a real bug the gates caught):
text ids placed only in codebook column 0 (the reference broadcasts
them across all 8), the CJK whitespace pass running before the
space-run collapse, and the layer penalty zipped against the flat
confidence (only the first row penalized instead of each cell's
column).

Rust gates: `cargo test -p turbospark-audio --lib omnivoice` (4 tests).

## Open items

- Real-checkpoint gate not run (fixtures are seeded tiny instances);
  the `mlx-community/OmniVoice-bfloat16` backbone plus the full
  HiggsAudioV2 tokenizer is the recorded open item.
- `class_temperature > 0`, batch generation, and the duration
  estimator (`duration.py`) are ported only at the call sites that the
  fixture exercises (`duration_s` given; the rule-based estimator stays
  reference-side).
- The reference-audio encode path (semantic fusion + PyTorch CPU
  tokenizer) is out of contract; reference tokens are caller-supplied.
