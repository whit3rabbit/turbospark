# arktts (Audio8 TTS preview family)

Port of `mlx_audio/tts/models/arktts/` at mlx-audio 0.5.8, pinned to
[`e1b19b9054bf163f5d812221a54fcc346f1890e9`](https://github.com/Blaizzy/mlx-audio/tree/e1b19b9054bf163f5d812221a54fcc346f1890e9/mlx_audio/tts/models/arktts)
(mlx 0.32.3). The architecture is a DualAR transformer plus a bundled
44.1 kHz codec: a slow AR stack predicts ONE semantic token per audio frame
and a fast AR stack predicts that frame's residual codec codebooks, then the
codec turns the code grid into audio. Two checkpoints share the `arktts`
model_type and are told apart by `slow_backbone`:

- `arktts` (default, Audio8-TTS-Preview-0.6b): pure-attention slow stack,
  full-vocabulary semantic logits tied to the input embedding
  (`logits = normalized @ embeddings.T`), EOS at `eos_token_id`.
- `falcon_h1` (Audio8-TTS-Preview-0.1b): the hybrid Mamba-2 + attention slow
  stack consumed through [`crate::lm::falcon_h1`]
  (`FalconH1Model::load_without_embed_table` + `forward_stack`), with a
  compact `codebook_size + 1` semantic head (index i means semantic token
  `semantic_begin_id + i`, index `codebook_size` means EOS) and the
  embedding multiplier applied at runtime to the COMPOSITE embedding.

Sampling reproduces the reference exactly: the semantic-range logit filter,
the legacy top-k/top-p order (filter BEFORE temperature, INCLUSIVE
cumulative softmax, rank 0 always survives), the exponential race
`argmax(softmax / -ln u)` with one uniform per vocabulary entry, and the RAS
repetition rescue (a repeated semantic inside the window switches to the
`ras_top_p` / `ras_temperature` draw; EOS never switches).

Everything is portable single-batch f32: no Metal, no macOS APIs.

## Layout

- `mod.rs`: `ModelConfig` (both flavors, falcon fields carried verbatim for
  the rename-free pass-through), the family-local pure-attention Block
  (fused wqkv, static full-buffer KV cache, interleaved rope with
  bf16-rounded tables, position ids from the mask cumsum), the falcon
  slow-stack seam, the fast AR loop (with the position-0 cache warmup on the
  projected slow hidden), the sampler math (`legacy_top_k_top_p`,
  `exponential_race`, RAS switching), `prepare_prompt`, `prompt_segments`,
  and `Model::open`/`generate`.
- `codec.rs`: the decode-only codec (residual VQ `from_codes`, the post
  window transformer with the bf16-rounded rope table, the two kernel-2
  stride-2 upsample stages, and the Snake decoder at strides (8, 8, 4, 2)).
  The encode direction (encoder, downsample, pre-transformer, quantize
  argmax) is a documented refusal; voice-clone callers pass precomputed
  reference codes exactly like the higgs_audio family.
- `tests.rs`: fixture parity and regressions.

## Fixtures

`testdata/tts_arktts/`, generated by
[`tools/gen_arktts_fixtures.py`](../../../../tools/gen_arktts_fixtures.py)
against the pinned commit on the CPU device (mlx 0.32.3). The generator runs
the true reference module with three offline stand-ins: a word-level
`PreTrainedTokenizerFast` carrying the Mistral chat control tokens
(injected through `model._tokenizer`), tiny codec subclasses of the
reference `ArkttsCodec` classes that only shrink the hardcoded widths (every
forward method is inherited reference code), and a recorded
`mx.random.uniform` stream for the sampled case. Cases:

- `codec/`: codes -> waveform with per-stage traces (`from_codes`, post
  window transformer, upsample chain) plus a clamped-codes replay
  (over-range codes clamp to the top bin on both sides).
- `pure_attention/`: the 0.6b flavor at tiny dims (dim 32, 2 layers, 4
  heads, 2 kv, head 8, vocab 512, semantic 400..463, eos 499, codebooks 3)
  with greedy `generate_codes` end to end.
- `sampled/`: `do_sample=True` with the recorded uniform stream replayed
  through `generate_codes_with_uniforms`.
- `voice/`: the reference-voice path with the tiny codec's `encode` output
  recorded as reference codes (the Rust encode is a refusal).
- `falcon/`: the 0.1b flavor (unity muP multipliers, runtime embedding
  multiplier 1.25) greedy end to end.
- `eos/` and `falcon_eos/`: seed-searched checkpoints whose first greedy
  pick is EOS, so generation stops with no frames and model-level
  `generate` refuses.
- `sampling/` and `prompt/`: the sampler math on fixed logits (legacy
  filter with -inf pass-through, exponential race with recorded uniforms,
  RAS switch decisions) and the `_prepare_prompt` grids plus
  `_prompt_segments` part strings.

Every case is replayed on the Python side before freezing (fresh model,
same streams, bitwise-identical codes and waveforms; the established
recording caveat), and the seed searches enforce greedy decision margins of
at least 0.01 so the int-exact code gates are stable against the one place
the float paths could disagree (the bf16-rounded rope table; in practice the
tables reproduced mlx's bit-exactly).

## Measured tolerances

Frozen at freeze time (assertions use these, not re-measured values):

| Gate | Measured | Frozen tolerance |
|---|---|---|
| from_codes stage | 3.0e-8 | 1e-6 |
| post transformer stage | 2.4e-6 | 1e-5 |
| upsample chain stage | 3.3e-6 | 1e-5 |
| codec decode waveform (plain and clamped) | 2.1e-6 | 1e-5 |
| generation waveforms (greedy, sampled, voice, falcon) | 2.8e-6 | 1e-5 |

Generated codes are asserted int-exact.

## Scope decisions and deviations from the reference

- Batch size 1 and non-streaming: the reference's batch dimension and the
  GenerationResult telemetry are not ported. The batch-1 prompt grid is
  left-aligned (the reference left-pads batch rows to the longest row).
- Text tokenization is caller-owned: the reference loads the checkpoint's
  Mistral BPE tokenizer with `fix_mistral_regex=False`.
  [`prompt_segments`] exposes the exact prefix/suffix segment strings; the
  caller encodes each segment with `add_special_tokens=False` and
  concatenates the ids per side.
- The sampled draws are REPLAYED, not reproduced: the reference consumes
  `mx.random.uniform` streams (one uniform per vocabulary entry per race,
  three streams per frame: normal, RAS-high, and one codebook-width draw
  per remaining codebook position). The Rust replays recorded streams in
  fixtures; production runs use the crate-local threefry-style fallback
  RNG. mlx's RNG is not reproduced.
- `codec.encode` is refused (the reference codec encoder would need the
  full encoder/downsample/pre-transformer path; voice cloning passes
  precomputed reference codes, mirroring the reference's own
  `encode_reference` output shape).
- `norm_fastlayer_input: false` is honored on the decode steps but the
  published configuration always sets true; the fixture pins the true path.
- The post window transformer's `head_dim` (64), window size (128), and
  rope base (10000) are the reference's hardcoded values; the tiny fixture
  keeps them. The codec widths (`codec_hidden`, `codec_quantizer_input_dim`,
  `codec_decoder_channels`, `codec_semantic_codebook_size`,
  `codec_residual_books`, `codec_residual_codebook_size`,
  `codec_codebook_dim`, `codec_post_*`) ride config.json keys with the
  published checkpoint's values as defaults, so the fixture generator can
  shrink them; the published checkpoints carry none of these keys.
- The quantizer upsample is hardcoded to the reference's two kernel-2
  stride-2 stages (crop 0); the DECODER blocks carry the (8, 8, 4, 2)
  strides with kernel `2 * stride`. A real checkpoint conversion stores the
  sanitized MLX layouts the loader expects (`[out, K, in]` convs,
  out-first `[out, K, in]` transposed convs, per-channel Snake alphas).

## Verification evidence

`cargo test -p turbospark-audio --lib` is fully green at 15 arktts tests
over the 1296-test crate suite: config defaults, codec stage/waveform/
clamp/refusal parity, greedy + sampled + voice + falcon generation, the
sampler math, RAS switching (pure and falcon, including the EOS
never-switches rule), prompt building, and prompt segment strings. The
real-checkpoint gate (the published 0.6b/0.1b Audio8 checkpoints) is OPEN:
fixtures are seeded tiny instances, so hardware, memory, and quality
numbers stay unclaimed.
