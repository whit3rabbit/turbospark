# Echo-TTS

Port of the mlx-audio Echo-TTS family at
[`e1b19b9054bf163f5d812221a54fcc346f1890e9`](https://github.com/Blaizzy/mlx-audio/tree/e1b19b9054bf163f5d812221a54fcc346f1890e9/mlx_audio/tts/models/echo_tts):
a flow-matching diffusion transformer (EchoDiT) over Fish S1 DAC
latents compressed by a checkpoint PCA, with independent text and
speaker classifier-free guidance over a tripled batch, an euler
trajectory from t = 0.999 to 0, and a flattening-point crop of the
decoded waveform. 44.1 kHz (checkpoint config carries the sample
rate).

## Layout

- `config.rs`: `ModelConfig` / `EchoDiTConfig` / `SamplerConfig` with
  the reference `from_dict` defaults (latent 80, model 2048, 24 blocks,
  16 heads, text and speaker stacks at 1280, adaln rank 256, 40 euler
  steps, sequence length 640).
- `text.rs`: the byte-level intake. The whole vocabulary is one UTF-8
  byte with a zero BOS, plus `normalize_text_prompt` (fancy punctuation
  folded to ASCII, `[S1] ` prepended unless the text is already tagged).
  The family owns its intake; there is no external tokenizer.
- `dit.rs`: the denoiser. Text encoder (bidirectional, byte embeddings),
  speaker encoder (patched-latent causal transformer, in_proj divided
  by 6), optional latent-prefix encoder for blockwise continuation,
  joint attention blocks (self keys + optional latent KV + text KV +
  speaker KV, low-rank AdaLN, sigmoid gates), timestep conditioning.
- `sampler.rs`: both euler samplers - the whole-sequence
  `sample_euler_cfg_independent_guidances` (tripled batch:
  text `[cond, uncond, cond]`, speaker `[cond, cond, uncond]`) and the
  blockwise continuation sampler over latent-prefix KV caches, with
  optional temporal score rescaling and speaker-KV scaling with the
  mid-trajectory restore crossing.
- `audio.rs`: the PCA bridge (`ae_encode` / `ae_decode` over the
  checkpoint's `pca_state.safetensors`), the flattening-point scan, and
  the reference-audio speaker-latent extraction.

## Checkpoints

- `model.safetensors`: the DiT (loaded through the reference `sanitize`
  naming: `model.` prefix, `cond_module.N` renamed to
  `cond_module.layers.N`, PCA tensors skipped).
- `pca_state.safetensors`: `pca_components`, `pca_mean`, `latent_scale`.
- the Fish S1 DAC codec is a separate download
  (`fish_codec_repo`, e.g. `jordand/fish-s1-dac-min`); install it with
  [`Model::set_codec`] over the ported
  [`codec::fish_s1_dac`](../../codec/fish_s1_dac/README.md) module and
  its continuous-latent `encode_zq` / `decode_zq` API.
  [`Model::generate`] refuses to run without codec and PCA, like the
  reference.

## Reference quirks kept

- the joint attention's `_apply_rotary_half` slices `y.shape[-2]` of a
  `[batch, seq, heads, dim]` tensor, so it rotates the FIRST HALF OF
  THE HEADS at all positions, not a position range;
- the AdaLN low-rank path applies SiLU to its INPUT before the down
  projection (`up(down(silu(x))) + x`);
- attention gates are per-channel sigmoid vectors;
- the additive mask value is `-1e9`;
- RMS norms carry stored weights, including the per-head `[heads, dim]`
  q/k norms;
- the speaker mask is subsampled by the patch size inside the DiT call;
- the crop factor is hardcoded to 2048 samples per latent frame (the
  real codec's frame length); a shorter waveform passes through.
- the speaker encode chunk defaults to `640 * audio_downsample_factor`
  samples; `GenerateControls::speaker_audio_chunk_size` overrides it
  (the tiny fixture codecs need this).

## Verification

Fixtures at `crates/audio/testdata/tts_echo_tts/`, regenerated by
`tools/gen_echo_tts_fixtures.py` (run from the mlx-audio checkout with
the project venv; deterministic seeds, no network). The generator runs
the true reference modules on tiny seeded instances: EchoDiT at latent
8 / model 32 / 2 blocks, a tiny fish DAC (encoder_dim 8, hop 4, latent
16, dual codebooks 16/12, 2x2 downsample, window-4 pre/post
transformers), and an orthonormal-PCA state. Cases: `greedy_generate`
(whole-sequence euler, per-step DiT calls recorded),
`blockwise_generate` (blocks [8, 8, 8] with rescale and speaker-KV
scale/restore, latent-prefix KV traces), `voice_clone` (reference audio
through codec + PCA), `codec_zq` (standalone codec roundtrip plus the
crop math with a flattening tail), and `text_cases.json` (normalization
+ byte ids).

Measured parity on the frozen fixtures: text ids, masks, token counts,
flattening points, and speaker masks exact; text state 2.6e-6; euler
latents 4.0e-5 (greedy) and 6.2e-5 (blockwise) against a 1e-4 gate; PCA
waveforms 3.0e-6 relative against a 1e-5 relative gate (the tiny codec
amplifies absolute drift; the codec fixtures use the same relative
convention). The recorded `mx.random.normal` draws are replayed, so the
trajectories pin the reference sampler exactly.

Rust gates: `cargo test -p turbospark-audio --lib echo_tts` (9 tests),
plus the codec's `encode_zq` / `decode_zq` shape and determinism tests
in `codec::fish_s1_dac`.

Mutation checks: flipping the rope-half head range, the AdaLN SiLU
position, the per-channel gate, the batched-mask indexing, the PCA
matmul layout, or the ae_decode transpose each move the gates by 1e-2
or more (several were real bugs found and fixed during bring-up).

## Open items

- Real-checkpoint gate not run (fixtures are seeded tiny instances);
  the 44.1 kHz `jordand/fish-s1-dac-min` + Echo checkpoint path is the
  recorded open item.
- Streaming is refused (the reference raises NotImplementedError too).
- Batch generation (`generate_batch`) is not ported; single utterance
  per call.
