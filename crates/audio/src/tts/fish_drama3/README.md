# Fish Audio Drama 3 TTS family

Port of `mlx_audio/tts/models/fish_drama3/` (drama3.py, tower.py,
chunking.py, config.py) at mlx-audio
[`dad2087f790dfe96b07d5aac1405db4b578b411f`](https://github.com/Blaizzy/mlx-audio/tree/dad2087f790dfe96b07d5aac1405db4b578b411f/mlx_audio/tts/models/fish_drama3)
(Blaizzy/mlx-audio PR 1018, mlx 0.32.4). That is newer than the crate's
normative `e1b19b9`, which has no Drama 3. The codec stays at `e1b19b9`.

Built with Fish Audio. The weights are under the Fish Audio Community
License, whose terms `docs/FISH_DRAMA3_PHASE0.md` records.

Drama 3 pairs a 35B Qwen3.5-MoE text backbone (3B active per token) with a
temporal codebook tower and the Fish S1 DAC (`src/codec/fish_s1_dac/`). Per
frame (46.4 ms of 44.1 kHz audio): the semantic head picks the main token
(a semantic token or EOS) from the backbone's final normed hidden state,
with repetition-aware resampling. The tower samples codebooks 1..9 from the
same state. The frame is re-embedded as
`(embed[main] + codebook_emb[c1 + vocab]) * 2^-0.5` and fed back.

The backbone does not live here. It runs as a headless `QwenGdnMoe` trunk on
Metal with streamed routed experts (`crates/runtime`'s `HiddenTrunk`, behind
this module's `Backbone` trait). Everything in this directory is portable
single-batch f32: no Metal, no macOS APIs. The runtime supplies the device
paths through two seams: a `TowerModel` (its Metal tower,
`crates/runtime/src/fish_drama3_tower.rs`, against `CpuTower` here) and the
codec's `DacExec` (`crates/runtime/src/fish_drama3_codec.rs`).

## Layout

- `chunking.rs`: the prompt's text rules (structural tokens refused, speaker
  tags 0..15) and long-text chunking (about 300 bytes, at most three
  speakers per chunk, uncuttable special tokens, paired tags, and cues).
- `sampling.rs`: the reference's top-k then top-p rule (temperature first,
  cumulative mass over the full vocabulary, the crossing candidate dropped
  unless it ranks first) and RAS (window 16, retry at T 1.0, k 30, p 0.95).
- `config.rs`: the root `config.json` and the tokenizer agreement check.
- `prompt.rs`: the `reference-bracket-v1` frame builder, each segment
  tokenized on its own.
- `tower.rs`: the tower (enrichment and residual layers, gated GQA with
  interleaved partial rope, a KV cache per block across frames) and the
  semantic head, 8-bit linears kept packed. `TowerEmbeddings` holds the
  per-layer input embeddings any tower uses, and `TowerModel` is the seam a
  device tower implements.
- `generate.rs`: the generation loop over any `Backbone`, the install layout
  (`config.json`, `tokenizer.json`, `tts_side.safetensors`,
  `codec.safetensors`, `trunk/`) and `Drama3::open`.

## Verification

Fixtures: `testdata/fish_drama3/`, regenerated by
`tools/gen_fish_drama3_fixtures.py` from the pinned commit.

- Chunking: `split_text`, the uncuttable-span matcher, validation, and tag
  placement equal the reference's output on every fixture case.
- Prompt: frame rows and the system-block boundary equal `build_frames` on
  three cases, with the reference test's tiny tokenizer: no reference, a
  reference with two speakers, and two references with two history turns.
- Tower: on a tiny random-weight tower with the real structure (2 enrichment
  and 3 residual layers, 4 query and 2 KV heads, and 8-bit linears), a
  teacher-forced prefill and three decode frames give identical greedy
  codes. Head logits agree within 1.5% of the largest magnitude, against a
  3% gate: the reference runs bf16 activations and this port f32. The
  backbone input mix agrees within 1%.
- Mutation checks: GQA head mapping, half-split rope, the dropped unseen
  codebooks, the `wqkv` split order, the semantic mask, tag-name
  backtracking, the decimal-point rule, the system-row boundary, and the
  voice-prefix restore each fail a test when broken.

- Real checkpoint, end to end: the Metal trunk, the Metal tower and the
  streamed Metal codec turn a 34-word sentence into 9.3 s of audio that
  Parakeet Redux transcribes word for word, in a 5.57 GB peak footprint.
  Backbone and tower take 58 ms per frame warm against the 46.4 ms budget
  (`docs/FISH_DRAMA3_PHASE0.md`).
- Real prompt: with the pinned 248k-entry tokenizer, frames match the
  reference on four cases (opt-in, `TURBOSPARK_FISH_DRAMA3_MODEL`).

Not yet verified here: teacher-forced parity against mlx-audio on the real
checkpoint, a word-error-rate set, and real time (generation is about 1.25
times real time).

## Scope and divergences

- One reference voice per call in the runtime surfaces. The loop itself
  takes several.
- Draws use the crate's threefry keys, not MLX's global random state.
  Sampled codes differ from the reference's for the same seed, while the
  distributions match.
- The nine residual heads score 4096 codes each. The Fish S1 DAC's acoustic
  books hold 1024 (`FishS1DacConfig::build_ae()`), and the codec refuses a
  code past them, which fails the whole request. The loop draws from the
  first 1024 entries of each head. The cut comes before top-k and top-p, so
  the nucleus mass runs over codes the codec can decode
  (`Drama3Config::acoustic_codebook_size`). Book 0, the main token's
  semantic code, keeps all 4096. Whether the pinned reference does the same
  was not compared when this was added.
- Python's `\w` is approximated by `char::is_alphanumeric` plus `_`, and
  `str.isdigit` by `char::is_numeric`, in the chunker's edge characters.
- No `speed` and no `instruct`: delivery cues go inline (`[whispers]`).
- The default main-draw recipe is Fish Audio's serving recipe
  (`SamplingParams::FISH_SERVING`: temperature 1.0, top-p 0.9, top-k 30, the
  same RAS), the default of SGLang-Omni `fishaudio_drama3/speech_request.py`.
  mlx-audio defaults to 0.7, 0.7 and 30, kept as `SamplingParams::REFERENCE`
  for parity runs. Under it the first draw in a pause keeps only a few
  silence tokens, and a sentence gap or a turn change trapped 12 of 24 test
  takes in silence until the chunk's cap, against 4 of 24
  (`docs/FISH_DRAMA3_PHASE0.md`, sampling recipe).
- `ChunkEnd` also reports the chunk's `limit` (its text cap or `max_frames`),
  which the reference does not track.
- The loop resamples a pause that outlives every healthy one
  (`PauseGuard`, `GenerateOptions::pause_guard`), which the reference does
  not. It reads each main token as voiced or silent from a table of 4,096
  bits (`voiced.rs`), holds a pause's frames back, and rolls the backbone and
  tower back to the pause's start when it reaches 128 frames. Six rollbacks
  per chunk at most. A pause that ends by itself, and every take the guard
  never fires on, go out as the reference's loop gives them, and
  `pause_guard: None` is that loop. An explicit `[pause]` trapped 3 of 6 takes
  under the serving recipe (`docs/FISH_DRAMA3_PHASE0.md`, Pause guard).
