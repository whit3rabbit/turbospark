# TurboSpark

TurboSpark is a macOS app and Rust library for running language models locally on Apple Silicon. Start with the desktop app, or use the Rust and Swift APIs to build an integration.

## Choose a path

- [Install and use the desktop app](https://app.gitbook.com/s/7snUJsZfxrqIt5S95nxb/desktop)
- [Integrate with the Rust library](https://app.gitbook.com/s/gJ02Ufhn7qpqBrO3Frio/rust)
- [Use the Swift bindings](https://app.gitbook.com/s/gJ02Ufhn7qpqBrO3Frio/swift)
- [Connect an app to the local HTTP API](https://app.gitbook.com/s/7snUJsZfxrqIt5S95nxb/call-the-local-api)

## Get started with the app

Install TurboSpark, open it, then use the model selector to discover and install a model. The [desktop guide](https://app.gitbook.com/s/7snUJsZfxrqIt5S95nxb/quickstart) walks through the first chat.

Models differ in quality, memory use, and hardware support. Check the [model catalog](https://app.gitbook.com/s/7snUJsZfxrqIt5S95nxb/models) before downloading a large checkpoint.
