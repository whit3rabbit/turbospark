# The `state#N` ledger

`AppModel` and its extensions carry `(state#N)` markers on the comments
that explain a fixed state-layer defect. The numbers are inline references
with no central file otherwise, so before this index a reader who found
`state#9` in a comment could only learn what it meant by grepping for other
mentions of it. This page is that index.

Add the next number here when you add a marker in source, or the index
rots the way the numbering did before it existed.
