# Tools

## Overview
Agent tool system of the app: definitions, executors, permission and sandbox gates, registry, MCP client, hooks, shells, web, file and planning tools. Each subdirectory owns one tool family.

## Subdirectories & Boundaries
- Automation: [./Automation/EGM.md](./Automation/EGM.md) - sleep, notification, cron and monitoring tools
- Browser: [./Browser/EGM.md](./Browser/EGM.md) - browser tool definitions and media policy
- Codemode: [./Codemode/EGM.md](./Codemode/EGM.md) - sandboxed script tool
- ComputerUse: [./ComputerUse/EGM.md](./ComputerUse/EGM.md) - computer-use tool definitions and executor
- Core: [./Core/EGM.md](./Core/EGM.md) - permission engine, sandbox, command gate, tool call parsing and validation
- Custom: [./Custom/EGM.md](./Custom/EGM.md) - user and project custom tools
- File: [./File/EGM.md](./File/EGM.md) - read, write, patch and diff tools
- Guardrails: [./Guardrails/EGM.md](./Guardrails/EGM.md) - Forge guardrails verdicts
- Hooks: [./Hooks/EGM.md](./Hooks/EGM.md) - hook engine and models
- MCP: [./MCP/EGM.md](./MCP/EGM.md) - Model Context Protocol client
- Memory: [./Memory/EGM.md](./Memory/EGM.md) - memory tool
- Planning: [./Planning/EGM.md](./Planning/EGM.md) - interactive planning tools
- Projects: [./Projects/EGM.md](./Projects/EGM.md) - project doc, artifact and worktree tools
- Registry: [./Registry/EGM.md](./Registry/EGM.md) - tool catalog and registry
- Repl: [./Repl/EGM.md](./Repl/EGM.md) - REPL tool
- Tasks: [./Tasks/EGM.md](./Tasks/EGM.md) - task, sub-agent and batch tools
- Terminal: [./Terminal/EGM.md](./Terminal/EGM.md) - shell execution and classification
- Web: [./Web/EGM.md](./Web/EGM.md) - web fetch, HTTP request, code search
