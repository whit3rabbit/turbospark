# State

## Overview
The app's state and persistence layer, and its largest directory. `AppModel` is the single `@MainActor` `ObservableObject` holding published state, and about 80 `AppModel+*.swift` extensions carry behavior: the generation turn, tool and agent loop, queueing, compaction, ghost chats, model loading and installation, the HTTP server, profiles and backup. Beside them sit the persisted value types and file stores (chats, settings, projects, MCP, memory), the encrypted profile vault and SQLCipher database, agent, skill and plugin registries, subagent execution, model library and drive handling, and pure policy and row-model helpers that views and tests read.

## Invariants
- Behavior lives in extensions, `AppModel.swift` holds state and wiring only [AppModel.swift:AppModel]. Turn code takes chat and project as arguments and never reads the selection, because a turn outlives selection changes [AppModel+Generation.swift:executeGenerationTurn], [AppModel+Hooks.swift:dispatchLifecycleHook], [AppModel+Sampling.swift:effectiveSamplingSettings].
- `selectedChat` is a pure read: no `@Published` mutation from a getter used in view bodies [AppModel+Chat.swift:selectedChat].
- Ghost chats never reach disk: rows keep empty content and the vault holds payloads under a per-launch key; the `isGhost` filter in persistence is the hard guarantee [AppModel+Ghost.swift:mutateGhostPayload], [GhostChatVault.swift:GhostChatVault]. Ghost chats are also excluded from recall, export, split panes and prompt history [AppModel+ConversationRecall.swift:conversationRecallEligible], [AppChatExport.swift:exportChat], [AppModel+SplitView.swift:splitPaneChats], [InputHistory.swift:InputHistoryEntry].
- Decoding is tolerant: one bad field or element must not lose a whole archive, settings file or server list, and unknown permission values decode to ask, never allow [TolerantDecoding.swift:decodeLossyArray], [AppChat.swift:AppChat], [MacAppSettings.swift:MacAppSettings], [AppProject.swift:AppProjectPermissions], [GlobalMcpFileStore.swift:GlobalMcpFileStore].
- Test hosts get a per-process temp storage root so tests cannot overwrite real chats, `TURBOSPARK_STATE_DIR` pins the root, and the active profile is resolved once per process, so switching profiles is a relaunch [AppStorageRoot.swift:AppStorageRoot], [UserProfile.swift:UserProfileStore], [AppModel+Profiles.swift:switchToProfile].
- Vault lock order is the operation gate first, then the store lock; nothing enters the gate while holding the store lock [ProfileVault.swift:ProfileVaultOperationGate]. Every `ProfileRepository` call throws `VaultError.locked` without a session, and an undecodable record is quarantined before the error propagates [ProfileRepository.swift:ProfileRepository].
- Passphrases are NFC-normalized, 15 to 1024 characters, PBKDF2-HMAC-SHA256 with 600000 rounds [ProfileVaultCrypto.swift:derivePassphraseKey]. The database refuses to open without a SQLCipher version and sets WAL, secure_delete and memory security [ProfileDatabase.swift:ProfileDatabase].
- Managed assets are chunked AES-GCM (`TSASET01`) keyed by an HMAC content id; chats store paths and metadata, never bytes [ManagedAssetStore.swift:ManagedAssetStore], [AppArtifact.swift:AppArtifact].
- Any project repository git call goes through `HardenedGit` (pager, fsmonitor and hooks disabled) [HardenedGit.swift:HardenedGit], [AppModel+GitParity.swift:runGit], [WorktreeModel+Git.swift:runGitCommand]. Text that reaches the system prompt (rules, agent and skill files) must resolve inside its root via `PathContainment` [PathContainment.swift:isContained], [ProjectRuleDetector.swift:readText], [AgentParser.swift:parseFile], [SkillParser.swift:parseFile].
- Agent loop: one tool call runs per turn, the rest are recorded as denied, except an all-agent batch [AppModel+AgentLoop.swift:handleExtractedToolCalls]. Subagents have no approval UI (ask denies), nesting is capped at `maxSubagentDepth` (2), at most 4 background agents run, and `maxTurns` is clamped to 50 [SubagentRunner+Gate.swift:permissionRefusal], [SubagentRunner.swift:runBody], [AppModel+Subagents.swift:maxRunningBackgroundAgents], [AppAgentDefinition.swift:AppAgentDefinition].
- Archived tool output loads only when byte count and SHA-256 match its ref [AgentEfficiency.swift:ToolObservationStore.load]. Fused validation runs only after a verified successful mutation [AppModel+AgentEfficiency.swift:executeApprovedTool].
- Cancellation is cooperative; Stop guarantees only that no further turn or tool starts, and a pending approval is denied and recorded [AppModel+Cancellation.swift:cancel]. A continuation turn's total budget is limit times (max continuations + 1) [AppStreamRecovery.swift:generateUntilComplete].
- Auto-compact fires at 80 percent of usable context and refuses when usable is zero or less; microcompact fails safe and leaves the transcript untouched [AppChatCompaction.swift:shouldAutoCompact], [AppChatMicrocompact.swift:apply]. Summary injection uses one shared function for prompt and estimate [AppModel+History.swift:insertingSummaryInjection].
- Network policy is a ceiling: deny wins in every project mode, and metadata and link-local hosts are always denied [AppNetworkPolicy.swift:AppNetworkPolicy].
- Both references (engine and `serverAttachedSessions`) must be dropped for weights to leave memory, and every site clearing `session` calls `detachChatSessionFromServer`. An empty server key starts an unauthenticated server, so launch auto-start refuses without a key [AppModel+ServerAttachment.swift:detachChatSessionFromServer], [AppModel+Server.swift:autoStartNeedsKey].
- A model being moved is never loaded, opened or rendered; the engine moves files and the app only rewrites its own state [AppModel+LoadGate.swift:requestLoad], [AppModel+Moves.swift:performMove]. Engine-side library and install errors are localized by fault code, never by engine text, and drive-supplied names go through `UntrustedText` [LibraryActionText.swift:sentence], [ModelMoveText.swift:failure].
- Volume unmount approval is answered from lock-protected memory within 100 ms, and a timeout approves [VolumeMonitor.swift:approvalTimeout], [EjectDecisionState.swift:decide], [LibraryEjectCoordinator.swift:unmountRequested].
- `allowedSlotCounts` must match the engine's `ALLOWED_CACHE_SLOTS` (plus 0), since a refused value panics the engine [AppRuntimeOptions.swift:allowedSlotCounts]. Sampling values are always clamped before UInt32 conversion [AppSamplingSettings.swift:clamped].
- Credentials are opt-in: server and TypeSafe keys touch the Keychain only when the toggle is on [AppModel+ServerKey.swift:setServerKeyInKeychain], [AppModel+TypeSafeAPI.swift:startTypeSafeServer].
