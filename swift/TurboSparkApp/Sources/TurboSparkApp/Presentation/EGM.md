# Presentation

## Overview
Rendering and text-preparation helpers for chat transcripts and attachments. It covers four jobs: (1) turning model markdown into views or attributed strings (MarkdownUI theme, code-block chrome, native syntax highlighter, interactive table model, a plain `NSAttributedString` markdown renderer, and the AppKit transcript document controller); (2) cleaning tool output (ANSI stripping, SGR colorizing, tail truncation); (3) extracting prompt text from attached PDF, Office and plain-text files under strict size and time limits; (4) small UI services (relative timestamps, time-of-day greetings, text-to-speech, long-message preview windowing). Nothing here owns app state: each type is either a pure function or a thin service driven by the views above it.

## Interface
- Markdown views:
  - `ChatMessageMarkdownView` (MarkdownUI `Markdown` with `Theme.turboSpark(ui:code:palette:onPreviewHTML:)`; `AppFontDescriptor.markdownFamily`) [ChatMessageMarkdownView.swift:ChatMessageMarkdownView].
  - `CodeBlockContainer` (language tag, Preview, Copy; static `chartHTML(language:code:)` builds echarts or Chart.js preview pages) [ChatMessageMarkdownView.swift:CodeBlockContainer].
  - `CodeSyntaxHighlighter` (`family(forLanguage:)`, `highlight(_:language:)` returns nil for unknown languages or oversize blocks, `maxHighlightLength`, `Family`, `TokenKind`) [CodeSyntaxHighlighter.swift:CodeSyntaxHighlighter].
  - `MarkdownTableGrid` (`segments(in:)` splits prose from tables, `parse`, `sorted(byColumn:direction:)`, `sortedRowIndices`, `tsv(range:)`, `csv()`, `markdown`) [MarkdownTableGrid.swift:MarkdownTableGrid].
  - `MessageContentPreview` (`make(_:...)` returns a head+tail `Preview` for long text, else nil) [MessageContentPreview.swift:MessageContentPreview].
- Attributed-string transcript:
  - `ResponseMarkdownRenderer` (`render(_:)` returns `Result` with `usedFallback`; `plainText(_:)`) [ResponseMarkdownRenderer.swift:ResponseMarkdownRenderer].
  - `InstructionTranscriptDocumentController` (`@MainActor`; `synchronize(storage:history:response:reasoning:isTerminal:showsPrefillPlaceholder:)` returns `UpdateResult` with a `Mutation`; `advancePrefillAnimation`, `clampedRanges`, `shouldScrollToBottom`, `shouldRunPrefillAnimation`) and `InstructionTranscriptMessage` [InstructionTranscriptDocumentController.swift:InstructionTranscriptDocumentController].
- Tool output: `ToolOutputFormatter` (`stripAnsi`, `tailOutput` returning `OutputTail`) [ToolOutputFormatter.swift:ToolOutputFormatter]; `ANSIColorizer` (`segments(in:)`, `stripped(_:)`, `Palette`, `Segment`, `paletteFor256`, `paletteForRGB`) [ANSIColorizer.swift:ANSIColorizer].
- Document extraction: `DocumentTextExtractor` (`extract(from:)`, `supportedContentTypes`, `maximumExtractedCharacters`, internal `Limits`), `ExtractedPromptDocument`, `DocumentTextExtractionError` [DocumentTextExtractor.swift:DocumentTextExtractor]; `OfficeArchive` (internal, unzip-backed entry reader) [OfficeArchive.swift:OfficeArchive]; SAX parsers `FlowingTextXMLParser`, `SharedStringsXMLParser`, `WorksheetXMLParser`, `WorkbookXMLParser`, `RelationshipsXMLParser`, `WorkbookSheet`, helpers `localName(_:)` and `attribute(_:localName:)` [OfficeXMLParsers.swift].
- Small services: `MessageTimestampFormatter` (`relativeString`, `compactRelativeString`, `exactString`, `standardString`, all locale-parameterized) [MessageTimestampFormatter.swift:MessageTimestampFormatter]; `GreetingProvider.shared`, `Greeting`, `GreetingTimeSlot` (`slot(forHour:)`, `randomGreeting`, `greeting(at:)`) [GreetingProvider.swift:GreetingProvider]; `AppSpeechSynthesizer.shared` (`@MainActor`, `toggleSpeech`, `speak`, `stop`, published `speakingMessageID` and `isSpeaking`) [AppSpeechSynthesizer.swift:AppSpeechSynthesizer].
- Subdirectories: none.

## Invariants
- `MessageContentPreview` shrinks only the string handed to the view, never the stored message. It has a cheap `utf8.count` precheck before the O(n) `Character` count, and `includesTail: false` keeps the head only [MessageContentPreview.swift:make].
- `CodeSyntaxHighlighter` returns nil past 12,000 characters or for unknown tags so streaming re-renders stay bounded; callers must fall back to MarkdownUI. Block-comment and string state carry across lines [CodeSyntaxHighlighter.swift:maxHighlightLength, highlight].
- Chart preview HTML embeds the fence body as `application/json` data only after `JSONSerialization` validation, escaping `<`, U+2028 and U+2029. A non-JSON body yields nil and no preview. Previews exist only when `onPreviewHTML` is non-nil [ChatMessageMarkdownView.swift:chartHTML, isPreviewableHTML].
- `MarkdownTableGrid.segments` must never detect tables inside ``` or ~~~ fences (CommonMark fence open/close rules), otherwise the fence is cut in half and swallows later prose. Ragged rows are padded to header width, never truncated. `\|` is a literal pipe, and `markdown` re-escapes pipes so copy/paste round-trips [MarkdownTableGrid.swift:segments, cells, markdown].
- Sorting decides numeric-vs-text for the whole column (per-pair detection is not a strict weak ordering). Blank cells sort last in both directions. Ties compare equal in both directions. `sortedRowIndices` maps display position back to the original row positionally, not by value [MarkdownTableGrid.swift:sortedRowIndices].
- CSV/TSV export neutralizes formula injection: cells starting with `=`, `+`, `-`, `@` (after whitespace) get a leading `'` unless they are plain numbers. TSV escapes tab and newline; CSV quotes on separator, quote or newline [MarkdownTableGrid.swift:delimited].
- `ResponseMarkdownRenderer.render` falls back to raw text (`usedFallback == true`) for odd fence counts, any HTML-like tag, any markdown image, any table block, an empty result, or a parse error. The fallback is the unmodified source [ResponseMarkdownRenderer.swift:requiresRawFallback, containsUnsupportedBlock, render].
- `InstructionTranscriptDocumentController` is `@MainActor`. A rebuild is forced when history changes, the new response or reasoning is not a prefix extension of the old, a finalized turn becomes non-terminal, or the placeholder state flips. A terminal update always rebuilds with no placeholder and marks `isFinalized` (mutation `.finalized`). `assistantRange` is recomputed on every rebuild. Even the `.appended` path rebuilds the whole document [InstructionTranscriptDocumentController.swift:synchronize, rebuild].
- Prefill placeholder animation runs only when requested, response and reasoning are empty and the turn is not terminal [InstructionTranscriptDocumentController.swift:shouldRunPrefillAnimation].
- `ToolOutputFormatter.stripAnsi` must never treat a bare 0x9B/0x9C/0x9D byte as a control, because those are UTF-8 continuation bytes; C1 controls are only the two-byte forms `C2 9B/9C/9D`. `tailOutput` strips ANSI before measuring lines and characters [ToolOutputFormatter.swift].
- `ANSIColorizer.segments` is a single pass that avoids O(n) `count` per escape (quadratic on big colored output). It supports only the listed SGR codes, strips every other CSI and any OSC, and merges adjacent segments with identical style. 24-bit and 256-color values are quantized to the 16-entry palette [ANSIColorizer.swift:segments, append, nearestRGB].
- Document extraction is bounded on every branch: plain text files are size-checked via `AppFileReadLimits` before reading, archives by `Limits` (32 MiB per entry, 64 MiB total, 30 s), output by `maximumExtractedCharacters` (240,000), PDFs stop after 2x that. Password-protected PDFs and PDFs without a text layer error out rather than returning empty text. Text is normalized (CRLF to LF, NUL removed, blank runs collapsed) and must be non-empty [DocumentTextExtractor.swift:extract, extractPDF, normalize].
- `OfficeArchive` copies the document to a fixed name `doc.zip` in a private 0700 temp directory before running `unzip`, because `unzip` treats its archive argument as a wildcard and a user-controlled file name could resolve to a sibling file. Output is read via `poll`/`read` with a hard byte cap and deadline; on limit or timeout the process is terminated. The work directory is removed in `deinit`, and cleaned in `init` on failure because a throwing init does not run `deinit` [OfficeArchive.swift:init, runUnzip, deinit].
- The tab-definition depth counter in `FlowingTextXMLParser` keeps `<w:tabs>`/`<a:tabLst>` child `tab` elements from emitting tab characters [OfficeXMLParsers.swift:FlowingTextXMLParser].
- `AppSpeechSynthesizer` ties state to a specific `AVSpeechUtterance` identity (`currentUtterance`): delegate callbacks arrive on a later main-actor turn, so a stale `didCancel` for message A must not clear message B's state [AppSpeechSynthesizer.swift:utteranceEnded].
- `MessageTimestampFormatter` builds formatters per call and uses the passed `locale` (the in-app language), not the system locale; "Just now" is resolved through `AppStrings` for the picker's language [MessageTimestampFormatter.swift:justNow].
- Greeting resolution tries script, region, bare language code, any prefix match, then `en`. If `greetings.json` is missing or empty, a static English fallback set is used; with no eligible greeting the literal "Welcome!" is returned [GreetingProvider.swift:resolve, loadCatalog, randomGreeting].

## Side Effects
- Process spawn: `OfficeArchive.runUnzip` launches `/usr/bin/unzip` (`-l` listing, `-p` entry) with stderr to null [OfficeArchive.swift:runUnzip].
- Disk: `OfficeArchive` creates `turbospark-office-<UUID>` in `FileManager.default.temporaryDirectory` with 0700 permissions, copies the document into it, and deletes it on deinit or failed init [OfficeArchive.swift:init]. `DocumentTextExtractor` reads user files, using `startAccessingSecurityScopedResource` and `stopAccessingSecurityScopedResource` around reads [DocumentTextExtractor.swift:extract]. `GreetingProvider` reads bundled `greetings.json` once at init [GreetingProvider.swift:loadCatalog].
- Pasteboard and accessibility: `CodeBlockContainer.copyCode` clears and sets `NSPasteboard.general`, posts an `AccessibilityNotification.Announcement`, and uses a `Task` with a 1.5 s sleep to reset the "Copied" state [ChatMessageMarkdownView.swift:copyCode].
- Audio: `AppSpeechSynthesizer` speaks through a shared `AVSpeechSynthesizer` using the current language voice [AppSpeechSynthesizer.swift:speak].
- Network: chart preview pages the view generates reference `cdn.jsdelivr.net` scripts, but loading is done by the preview panel (not this directory), which asks for network access per page [ChatMessageMarkdownView.swift:chartHTML].
- Singletons: `GreetingProvider.shared` and `AppSpeechSynthesizer.shared`. No UserDefaults, Keychain, NotificationCenter or FFI calls in this directory.
