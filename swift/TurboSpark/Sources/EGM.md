# Sources

## Overview
SwiftPM source roots of the TurboSpark package: the C ABI module and the typed Swift wrapper over it.

## Subdirectories & Boundaries
- CTurboSpark: [./CTurboSpark/EGM.md](./CTurboSpark/EGM.md) - hand-written C header, module map and staged Rust static archive.
- TurboSpark: [./TurboSpark/EGM.md](./TurboSpark/EGM.md) - Swift wrapper: sessions, server, catalog, libraries, audio, embeddings, OCR, image sessions.
